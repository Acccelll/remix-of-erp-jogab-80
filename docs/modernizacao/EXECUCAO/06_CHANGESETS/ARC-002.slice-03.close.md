# ARC-002.slice-03.close — Encerramento do slice de Veículos

**Onda:** 6 · **Prioridade:** P1 · **Tipo:** REF/MIGRAÇÃO
**Achado:** ARC-002 (god-context)

## Escopo

Encerra o slice-03, com todos os consumers reais de veículos migrados para `useVeiculosContext()`.

## Consumers migrados

- `src/pages/Veiculos.tsx`
- `src/components/frotas/VeiculoProfileDialog.tsx`
- `src/pages/Board.tsx` (bloco de veículos)

Consumers de leitura via agregadores (`useAppRead`, `useCatalogos`) permanecem inalterados — a fachada continua servindo `veiculos` a partir de `useApp()`; a mudança de fonte-de-verdade acontecerá quando o estado de veículos for movido para dentro do `VeiculosProvider`.

## Critérios preservados

- Sem alteração de UI, filtros, mobilização ou persistência.
- `useApp()` mantém compatibilidade para consumers não migrados.
- Typecheck (`tsgo`) verde.
