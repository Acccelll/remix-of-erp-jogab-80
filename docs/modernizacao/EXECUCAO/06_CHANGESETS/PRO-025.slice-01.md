# PRO-025.slice-01 — Lookahead: repetir pacotes da semana anterior

**Onda:** 7 · **Achado:** PRO-025 · **Tipo:** NEW · **Escopo:** ISOLADA (M4)

## Problema

Lookahead exigia recadastrar manualmente os pacotes recorrentes a cada
semana; não havia ação para replicar a semana anterior — o que é justamente
o gesto natural do planejamento Last Planner semana a semana.

## Alterações

`src/pages/planejamento/Lookahead.tsx`
- Nova função `repetirSemanaAnterior(semAlvo)`:
  - Calcula a semana anterior via `semanaDe(sem - 7d)`.
  - Filtra pacotes cuja `semana_inicio` cai naquela semana; respeita o
    filtro `filtroObra` (se `todas`, replica de todas as obras).
  - Relê os pacotes de origem em `pacotes_trabalho` com todos os campos
    operacionais (`cronograma_item_id`, `descricao`, `responsavel_id`,
    `tamanho_estimado`, `unidade`, `criterio_conclusao`).
  - Insere clones preservando a duração original, com `semana_inicio =
    semAlvo` e `semana_fim` deslocado.
  - **Não** copia `status` — o novo pacote entra com o default do banco
    para forçar reavaliação de restrições.
  - Toasts: informativo quando não há origem; sucesso com contagem.
- `SemanaColuna` ganha prop `onRepetirSemanaAnterior` + botão `Copy` no
  header (`aria-label`, `title` explicativo).

## Validação

- `bunx tsgo --noEmit` limpo.
- Sem alteração de schema/RLS/repositório.

## Estado

**PRO-025 encerrado.** Uma ação por coluna reduz o retrabalho semanal.
