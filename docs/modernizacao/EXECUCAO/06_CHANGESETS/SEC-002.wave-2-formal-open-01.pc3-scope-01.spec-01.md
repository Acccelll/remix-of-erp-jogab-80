## 2. Fonte normativa do escopo (R97)

`scripts/sec002/verify-wave-2-preconditions.mjs :: verifyPC3()` exige literalmente:

1. **Loader presente:** arquivo `scripts/sec002/load-apply-map.mjs` deve existir no repositório.
2. **Export utilizável:** o módulo deve exportar **pelo menos uma** das seguintes formas:
   - função nomeada `loadApplyMap()`;
   - função nomeada `getApplyMap()`;
   - `export default` que seja função invocável sem argumentos.
3. **Versão canônica:** o objeto retornado pela função (ou, alternativamente, as constantes exportadas `SCHEMA_VERSION` / `schemaVersion`) deve informar `schema_version` (ou `schemaVersion`) **exatamente igual a** `v2026-07-12.4`.
4. **Paridade documental de bumps:** todos os changesets registrados em `SEC-001.README.md` cujo stem case-match `SEC-002.apply-map-01.<slug>` devem existir em **par** `spec-01.md` + `materialize-01.md`. Qualquer stem com apenas um dos dois retorna `E_WAVE2_PC3`.

Nenhuma outra propriedade é exigida por R97; propriedades adicionais são permitidas desde que não violem (1)–(4).

## 4. Contrato do loader previsto para R110/R111

Bloco canônico mínimo do futuro `scripts/sec002/load-apply-map.mjs`:

```javascript
// scripts/sec002/load-apply-map.mjs
// Loader determinístico do apply-map v2026-07-12.4 (SEC-002 / PC3).

import { readFileSync } from "node:fs";
import { resolve } from "node:path";

export const SCHEMA_VERSION = "v2026-07-12.4";
const APPLY_MAP_PATH = ".github/sec002-apply-map.json";

export function loadApplyMap(root = process.cwd()) {
  const abs = resolve(root, APPLY_MAP_PATH);
  const raw = readFileSync(abs, "utf8");
  const data = JSON.parse(raw);
  if (data.schema_version !== SCHEMA_VERSION) {
    throw new Error(`apply-map schema_version inesperado: ${data.schema_version}`);
  }
  return data;
}

export default loadApplyMap;
```

Detalhes adicionais (validação estrita de estrutura, cache, telemetria) são responsabilidade de R110 (spec do loader) e devem preservar as invariantes PC3S1–PC3S8.

1. Materializarem o loader em caminho diferente de `scripts/sec002/load-apply-map.mjs`.
2. Omitirem o export `loadApplyMap` ou o `export default`.
3. Retornarem `schema_version` diferente de `v2026-07-12.4`.
4. Lerem qualquer arquivo diferente de `.github/sec002-apply-map.json`.
5. Introduzirem escrita/mutação sobre o apply-map ou qualquer outro artefato de governança.
6. Promoverem `verify-wave-2-preconditions.mjs` a workflow obrigatório.
7. Bumparem o `apply-map` para versão diferente de `v2026-07-12.4` neste ciclo.
8. Introduzirem changeset `SEC-002.apply-map-01.<slug>` sem o par `spec/materialize` completo no mesmo apply.
