# ARC-002 · slice-24 — Onda 6

## Objetivo
Reduzir o acoplamento dos subcontextos de compatibilidade ao símbolo runtime `useApp`, substituindo `ReturnType<typeof useApp>["X"]` por `AppContextType["X"]` (tipagem nominal).

## Mudanças
- `src/contexts/AppContext.tsx`: `AppContextType` agora é `export interface`.
- Façades migradas para `import { useApp, type AppContextType } from "@/contexts/AppContext"` e uso de `AppContextType[...]`:
  - `ColaboradoresContext.tsx`
  - `PlayersContext.tsx`
  - `ObrasContext.tsx`
  - `ContratosContext.tsx`
  - `PatrimoniosContext.tsx`
  - `DocumentosContext.tsx`
  - `MobilizacoesPendentesContext.tsx`
  - `ClientesContext.tsx`
  - `VeiculosContext.tsx`
  - `FuncoesContext.tsx`

## Verificação
- `rg "ReturnType<typeof useApp>" src/` → 0 ocorrências.
- `tsgo --noEmit` → sem erros.

## Impacto
Nenhuma mudança de comportamento. Passo preparatório para desmembrar o `AppContext` em provedores independentes: o tipo `AppContextType` passa a ser a única fonte contratual das assinaturas de mutação, permitindo, em ondas seguintes, mover implementações para os próprios domínios sem reescrever tipagem das façades.
