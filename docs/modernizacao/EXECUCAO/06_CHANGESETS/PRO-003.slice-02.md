# PRO-003.slice-02 — Hook + UI de fechamento de competência (Fopag)

**Onda:** 07 · **Achado:** PRO-003 · **Slice:** 02/n

## Entrega
- `src/hooks/useDpFechamentoCompetencia.ts` — persistência local em
  `gestaobra:dp:fechamentosCompetencia`, wrappers de `fechar`, `reabrir`,
  `estaFechada`, `trava` e `ativo`, com hidratação assíncrona.
- `src/components/dp/CompetenciaFechamentoBar.tsx` — barra exibida no Fopag:
  badge Aberta/Fechada, quem fechou, motivo, botão **Fechar competência** /
  **Reabrir** (dialog com motivo obrigatório na reabertura). Responsável
  padrão vem de `currentPlayer.login`.
- `src/pages/dp/Fopag.tsx` — barra logo abaixo do `DpFilterBar`, respeitando
  a competência atualmente filtrada.

## Regras respeitadas
- Nenhuma cor hardcoded; usa Button/Badge/Dialog do design system.
- Regras validadas na camada pura (slice-01) — hook e UI são adaptadores.
- Feedback via `toast` (sonner) para sucesso/erro.
- Sem alteração de tipos backend nem migração; local-only nesta slice.

## Não escopo
- Trava efetiva dos formulários de HE/adiantamento/holerite (slice-03).
- Persistência no backend + auditoria em `audit_logs` (slice-04).
- Guardrails na importação de holerites (bloquear reimport em fechado).
