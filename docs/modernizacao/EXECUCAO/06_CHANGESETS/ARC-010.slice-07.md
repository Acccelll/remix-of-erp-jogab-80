# ARC-010.slice-07 — Remoção física de `obrasRepo.listResumo*`

## Escopo
Concluir ARC-010: excluir do repositório os três métodos depreciados e limpar os testes de contrato correspondentes.

## Alterações
- `src/lib/repositories/obras.ts`: removidos `listResumo`, `listResumoComCodigo`, `listResumoComCodigoNome` e o tipo `ObraResumo`. Comentário do repositório atualizado apontando `useObras()` como fonte única em runtime.
- `src/lib/__tests__/integracao/repositories-contrato.test.ts`: removidos 3 testes de `listResumo()` (obras). Suíte reduzida para 6 testes (fornecedores + getById).
- `src/lib/__tests__/integracao/repositories-contrato-m.test.ts`: removidos 5 testes das variantes `listResumo*` de obras. Suíte reduzida para 14 testes.

## Validação
- `tsgo --noEmit` limpo.
- `rg "obrasRepo.listResumo|ObraResumo\b" src/` → sem ocorrências.
- `vitest run repositories-contrato.test.ts repositories-contrato-m.test.ts` → 20/20 passando.

## Encerramento ARC-010
Fonte única de obras consolidada em `useObras()` (`@/hooks/useObras`) em todo o runtime; repositório mantém apenas projeções específicas (`listResumoComCodigo` foi removido — usar hook + derivação; `listComClienteId`, `listMinContrato`, `getCentroCustoTotvs`, `getById`, mutações permanecem).
