# ARC-012.slice-07 — Migração de `FinClientes` para `useClientes`

**Onda:** 6 · **Achado:** ARC-012 · **Slice:** 07

## Alterações
- **`src/pages/financeiro/FinClientes.tsx`**:
  - Remove import de `clientesRepo` e `useQuery`.
  - Passa a consumir `useClientes`, `useCreateCliente`, `useUpdateCliente`, `useDeleteCliente` e `fetchClienteObrasVinculadas` de `@/hooks/useClientes`.
  - `saveNew` → `createMut.mutateAsync(payload)`. `saveEdit` → `updateMut.mutateAsync({ id, patch })`. `doDelete` → `fetchClienteObrasVinculadas(qc, id)` + `deleteMut.mutateAsync(id)`.
  - Remove invalidações manuais `["clientes"]` (agora automáticas via hooks canônicos).
- **`src/hooks/useClientes.ts`**: exporta helper `fetchClienteObrasVinculadas(qc, id)` para uso imperativo (fluxo de confirmação de delete), reusando `clientesKeys.obrasVinculadas`.

## Comportamento
Sem regressão funcional. Chave de cache passa de `["clientes"]` para `["clientes","list"]` — todos os consumidores agora usam o mesmo domínio canônico.

## Validação
- `tsgo --noEmit`: limpo.
- `rg "clientesRepo" src/pages/financeiro/FinClientes.tsx` → sem ocorrências.
