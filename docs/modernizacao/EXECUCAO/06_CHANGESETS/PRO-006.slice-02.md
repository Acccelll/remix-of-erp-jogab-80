# PRO-006 · slice-02 — Efetivo do Board respeita a data do RDO

**Onda:** 07 · **Achado:** PRO-006 · **Depende de:** slice-01 (botão "Carregar do Board").

## Contexto

O slice-01 introduziu o atalho "Carregar do Board", mas a query
`rdo-colabs` filtrava apenas mobilizações **ativas hoje**
(`data_fim IS NULL`). Ao lançar um RDO retroativo ou de uma data em
que o colaborador já havia sido desmobilizado, o botão trazia lista
errada — ou vazia — obrigando o apontador a redigitar, exatamente o
problema que o achado pede para eliminar.

## Entrega

- `src/components/obra/RdoTab.tsx` — query `rdo-colabs` reescrita para
  buscar mobilizações **vigentes na data do RDO**
  (`data_inicio <= dataDia AND (data_fim IS NULL OR data_fim >= dataDia)`),
  com `dataDia` incluído na `queryKey` para invalidar cache ao trocar
  a data. Sem mudança de schema, sem alteração do fluxo offline.

## Escopo consciente

- Continua sem sincronia bidirecional: alterações posteriores na
  alocação não repropagam para RDOs já lançados.
- Não gera faltas automáticas — o operador ainda alterna
  Presente/Ausente por linha.
- Não altera o cache de 5 min: a chave por `dataDia` já resolve o
  invalidamento entre dias.

## Validação

- `bunx tsgo --noEmit` — limpo.
