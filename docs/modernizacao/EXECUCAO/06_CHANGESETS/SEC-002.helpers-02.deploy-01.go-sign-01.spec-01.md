## 1. Objetivo

Definir o contrato canônico de assinatura `GO` / `NO-GO` do GM (`Cappucceno`) para
`SEC-002.helpers-02.deploy-01`, usando como baseline o pacote de autorização R208'.

Este changeset **não assina**, **não publica função**, **não chama ferramenta de deploy**
e **não altera** código, banco, migrations, workflows ou configurações. Ele apenas fixa
quais campos tornam uma assinatura GM válida para destravar uma materialização futura.

---

## 2. Contrato de assinatura GO/NO-GO

A assinatura GM só será considerada válida se registrar, em documento ou envelope
equivalente de governança, todos os campos abaixo:

| Campo | Obrigatório | Regra |
|-------|:-----------:|-------|
| Decisão | ✅ | exatamente uma opção: `GO` XOR `NO-GO` |
| Assinado por | ✅ | `Cappucceno` ou substituto GM explicitamente indicado |
| Papel | ✅ | `GM` / aprovador final da execução controlada |
| Data | ✅ | ISO-8601 completa |
| Request baseline | ✅ | R208' · `SEC-002.helpers-02.deploy-01.go-request-01.spec-01.md` |
| Checklist | ✅ | PC1..PC7 verdes; PC8/PC9 SKIP por default |
| Janela de execução | ✅ se `GO` | intervalo aprovado para deploy controlado |
| Responsável de execução | ✅ se `GO` | DRI técnico que executará a materialização futura |
| Rollback owner | ✅ se `GO` | responsável por remoção/reversão caso smoke/log falhem |
| Motivo | ✅ se `NO-GO` | razão objetiva e próximo critério para reavaliação |

Qualquer assinatura incompleta mantém `helpers-02.deploy-01.materialize-01` bloqueado.

---

## 3. Efeito operacional da assinatura

- **Se `GO`:** autoriza abrir `SEC-002.helpers-02.deploy-01.materialize-01`, ainda com
  execução condicionada ao checklist de pré-deploy e ao plano de rollback do R208'.
- **Se `NO-GO`:** registra bloqueio explícito e impede deploy até novo request ou nova
  assinatura GM válida.
- **Se campos ausentes ou ambíguos:** assinatura inválida; nenhum deploy pode ocorrer.

Este contrato não altera a dependência paralela de D-3: `helpers-03.apply-01` continua
bloqueado até D-3 assinada e até `helpers-02` estar deployado.
