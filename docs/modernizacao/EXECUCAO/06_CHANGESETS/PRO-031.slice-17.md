# PRO-031 · slice-17 — Ordem de Compra na UI de parametrização

## Contexto
Slice-16 introduziu o tipo `ordem_compra` em `TipoDocumentoNumeravel` e a
emissão customizada na criação de OC. A UI de parametrização por empresa
(`EmpresaParametrizacaoDialog`) ainda não listava o tipo — sem esta entrada,
o usuário não conseguia configurar prefixo/padding/próximo para OC.

## Entrega
- `src/components/admin/EmpresaParametrizacaoDialog.tsx`
  - Adicionado `{ key: "ordem_compra", label: "Ordem de compra" }` à
    constante `TIPOS`, expondo os campos configuráveis para o novo tipo.

## Escopo consciente
- Recebimento fica fora: não há id pré-conhecido pelo cliente (fluxo via RPC
  atômica). Rollback determinístico exige refatoração do RPC — postergado.
- Contratos fica fora: fluxo fire-and-forget via `addContrato` no provider,
  exige propagar `empresaId` até a mutação. Postergado para slice específico.

## Validação
- `bunx tsgo --noEmit`: limpo.
- `bunx vitest run src/lib/empresa/`: 11/11 verdes.
