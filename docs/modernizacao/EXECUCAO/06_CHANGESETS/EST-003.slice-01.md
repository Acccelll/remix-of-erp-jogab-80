# EST-003.slice-01 — Inventário canônico das chaves de localStorage

**Onda:** 7 · **Achado:** EST-003 · **Tipo:** STD · **Escopo:** ISOLADA (Transversal)

## Problema

Persistência local espalhada em 20+ arquivos, com **quatro prefixos de marca
convivendo** (`planifik:*`, `obraflow*`, `buildflow:*`, `lovable.*`) além
de chaves sem prefixo (`go_token`, `notif-bell-*`, `obras:columnVisibility`).
Sem inventário, novas chaves reintroduzem colisões e novos prefixos.

## Alterações

1. **`src/lib/storage/keys.ts`** (novo)
   - `STORAGE_KEYS` — mapa congelado com todas as chaves atuais em uso.
   - `CANONICAL_PREFIX = "gestaobra"` + `LEGACY_PREFIXES` documentados.
   - `makeStorageKey(namespace, name)` — helper para gerar chaves NOVAS no formato canônico `gestaobra:<namespace>:<nome>`.
   - Nota explícita: renomear chaves legadas exige migração e fica para uma onda futura.

2. **Refatoração de call-sites** para importar do inventário (strings idênticas — sem migração):
   - `src/contexts/ThemeContext.tsx` — `planifik_theme`
   - `src/components/Layout.tsx` — `planifik:nav:openGroups`, `planifik:nav:recent`
   - `src/components/layout/CommandPalette.tsx` — `planifik:nav:recent`
   - `src/contexts/EmpresaContext.tsx` — `obraflow.empresaAtualId`
   - `src/components/layout/InstallPrompt.tsx` — `planifik:pwa:installDismissed`
   - `src/components/layout/NotificationBell.tsx` — `notif-bell-tipos-ocultos`
   - `src/lib/rpc-baseline.ts` — `buildflow:rpc-p95-baseline:v1`
   - `src/pages/financeiro/FinObras.tsx` — `obras:columnVisibility`
   - `src/pages/MobilizacaoProvisoria.tsx` — `obraflow:mob-prov`

## Validação

- `bunx tsgo --noEmit` limpo.
- Strings persistidas inalteradas — nenhum estado de usuário é perdido.

## Estado

**EST-003 encerrado (fase 1 — inventário).** Fica pendente para onda futura:
migração das chaves legadas para o prefixo canônico `gestaobra:*` com
`getItem(old) -> setItem(new)`.
