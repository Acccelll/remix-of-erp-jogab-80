# PRO-018 · slice-05 — Reaplicação de perfil salvo em abas ignoradas

**Onda:** 07 · **Achado:** PRO-018 · **Slice:** 05/n

## Entrega
- `src/lib/bms/excel.ts`:
  - `parseBmsWorkbook(file, { perfisLayout })` aceita perfis locais salvos.
  - Quando o parser automático ignora uma aba, tenta reprocessar a mesma aba com cada perfil salvo.
  - A aba reprocessada recebe `perfil_layout_id` e `perfil_layout_nome` para rastreabilidade na UI.
- `src/components/import/BmsImporter.tsx`:
  - Envia os perfis salvos ao parser no upload.
  - Mostra no resumo quantas abas foram reconhecidas por perfil.
  - Identifica, na tabela, qual perfil foi usado em cada BMS reprocessado.
- `src/lib/bms/__tests__/excel-perfil.test.ts`:
  - Cobre o fallback: sem perfil a aba é ignorada; com perfil salvo, a aba é reconhecida e soma o valor do mês.

## Regras respeitadas
- Fallback conservador: só atua depois de falha do reconhecimento automático.
- Sem persistência remota; usa apenas perfis locais já existentes.
- Sem alterar o contrato de importação das medições.

## Não escopo
- Editor visual/manual de colunas.
- Priorização avançada por cliente quando múltiplos perfis são compatíveis.
- Sincronização dos perfis entre usuários.
