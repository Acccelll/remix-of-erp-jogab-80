# PRO-018 · slice-06 — Editor manual de perfis de layout BMS

**Onda:** 07 · **Achado:** PRO-018 · **Data:** 2026-07-14

## Entrega
- `src/lib/bms/layoutPerfis.ts`: novo `atualizarPerfil(lista, id, patch)` puro,
  com tipo `BmsLayoutPerfilPatch` (nome/cliente/headerRow/colunas parciais) e
  reuso de `validarPerfil` no resultado final.
- `src/lib/bms/__tests__/layoutPerfis.test.ts`: caso cobrindo patch parcial
  (preserva colunas não informadas), rejeição de nome vazio e id inexistente.
  Suíte: 5/5 verdes.
- `src/hooks/useBmsLayoutPerfis.ts`: expõe `atualizar(id, patch)` persistindo
  via `STORAGE_KEYS.bmsLayoutPerfis`.
- `src/components/import/BmsImporter.tsx`: no catálogo "Perfis de layout
  salvos", cada item ganha botão **Editar** que abre um form inline com
  campos para nome, cliente, `headerRow` e todas as chaves de `ColMap`
  (`item…sv`). Alterações são salvas em `onBlur`; erros de validação viram
  toast e o valor não é persistido.

## Regras respeitadas
- Nenhuma alteração no parser (`parseBmsWorkbook`) ou nos tipos do workbook.
- Persistência 100% local (`localStorage`), sem chamadas remotas.
- Hook mantém contrato aditivo (`atualizar` opcional para consumidores).

## Não escopo
- Editor visual arrastando colunas sobre a planilha bruta.
- Versionamento/histórico de perfis.
- Sincronização entre dispositivos.
