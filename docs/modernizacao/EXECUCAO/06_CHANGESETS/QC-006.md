# QC-006 — Scripts de formatação Prettier

**Data:** 2026-07-11
**Onda:** 1
**Achado relacionado:** QC-002 (régua de lint/formatação)

## Contexto

QC-002 introduziu `.prettierrc.json` + `.prettierignore`, mas o binário e os scripts de execução não estavam disponíveis, o que impedia CI/desenvolvedores de invocar Prettier de forma padronizada.

## Mudança

- `prettier@3` adicionado como `devDependency`.
- `package.json` recebe dois scripts:
  - `bun run format` → `prettier --write .`
  - `bun run format:check` → `prettier --check .`

## Encadeamento

A reformatação em massa dos arquivos sinalizados por `prettier --check` não fez parte deste changeset inicial e foi executada posteriormente em janela dedicada: [QC-007](QC-007.md).

## Verificação

- `bun run format:check` executa; após [QC-007](QC-007.md), o gate fica verde.
- `bun run lint` e `bun run typecheck` seguem verdes.
