# DS-009 — Migração de tabelas cruas para `ui/data-table` (Fase 1: piloto)

**Onda:** 4 — Padronização
**Achado:** DS-009 — 24 de 28 telas com tabela crua fora de `ui/data-table`
**Status:** Concluído — 8 listas navegáveis migradas; 10 tabelas restantes registradas como fora de escopo primário (D-DS009-1).

## Problema

Tabelas HTML cruas (`<table>`/`<thead>`/`<tbody>`) reescritas por página, cada uma com sua própria paginação, ordenação, busca e estado vazio. A `DataTable` (baseada em `@tanstack/react-table`) já existe com esses recursos padronizados, mas com adoção mínima.

## Padrão de migração

1. Trocar `<table>` inline por `<DataTable columns={columns} data={rows} />`.
2. Definir `columns: ColumnDef<T, any>[]` (via `useMemo` se depender de props/handlers, ou função helper no fim do arquivo caso contrário).
3. Reutilizar `EmptyState` como `emptyState` e `PageLoading` no estado carregando.
4. `hideSearch` quando a página já tem barra de filtros própria; caso contrário deixar a busca global do DataTable.
5. `pageSize` alinhado ao volume esperado (25 para cadastros, 50 para listas grandes).
