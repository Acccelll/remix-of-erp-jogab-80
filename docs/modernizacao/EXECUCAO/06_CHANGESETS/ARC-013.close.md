# ARC-013 · close — Encapsulamento do repo de cronograma na camada de UI

## Resultado
Camada de UI (`src/components/**`, `src/pages/**`) totalmente desacoplada de `@/lib/repositories/cronograma`. Único consumidor autorizado passa a ser `@/hooks/useCronograma`, que exporta:

- Chaves: `cronogramaKeys.*`
- Query fns: `cronogramaQueryFns.*`
- Mutations: `useUpdateCronogramaItem`, `removerCronogramaCompletoObra`
- Passthroughs: `cronogramaFns`, `cronogramaRevisoesFns`, `cronogramaItemRevisoesFns`, `cronogramaBaselinesFns`, `cronogramaBaselineItensFns`, `cronogramaDependenciasFns`, `cronogramaCenariosFns`, `cronogramaCenarioItensFns`
- Tipos: `CronogramaItemInsert`, `CronogramaItemRow`, `CronogramaItemUpdate`

## Slices consolidadas
slice-01 a slice-41 (ver arquivos `ARC-013.slice-*.md`).

## Escopo fora do Achado (documentado)
Consumidores de camada de domínio permanecem por design:

- `src/lib/cronograma/recalcular-cpm.ts`
- `src/lib/cronograma/persistir-calendarios.ts`
- `src/lib/__tests__/integracao/repositories-contrato-*.test.ts`

Nenhum é UI. Migração eventual entra como Achado próprio (candidato: `ARC-013-domain`), fora de ARC-013.

## Validação final
- `rg "@/lib/repositories/cronograma" src/components src/pages`: sem ocorrências.
- `rg "@/lib/repositories/cronograma" src/hooks`: apenas `src/hooks/useCronograma.ts` (fonte canônica).
- `tsgo --noEmit`: limpo.
