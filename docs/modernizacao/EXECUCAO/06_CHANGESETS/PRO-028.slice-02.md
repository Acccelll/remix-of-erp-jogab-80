# PRO-028.slice-02 — UI de perfis reutilizáveis de permissões

**Onda:** 07 · **Achado:** PRO-028 (GM: sem perfis/papéis reutilizáveis)  
**Escopo:** aplicar perfis no cadastro de usuário e gerir o catálogo local.

## Entrega

- `src/components/gm/PerfisPermissaoDialog.tsx`: catálogo local (lista +
  formulário) para criar, editar e remover perfis por página, usando o
  hook `usePerfisPermissao` já entregue em slice-01.
- Página **Gerenciamento** (`src/pages/GM.tsx`):
  - Novo botão **Perfis** no header (apenas GM) abre o catálogo.
  - Diálogo Adicionar/Editar usuário ganhou bloco **Aplicar perfil**
    (seleciona um perfil e substitui o mapa de acessos do formulário) e
    ação **Salvar como perfil** (persiste os acessos atuais como novo
    perfil reutilizável).

## Regras respeitadas

- Aplicar perfil usa `aplicarPerfilEmPlayer(..., "substituir")` — a
  troca é explícita e visível antes de salvar o usuário.
- GM (`isGM`) permanece imune: os controles de perfil só aparecem para
  usuários não-GM, e não alteram o campo `isGM`.
- Persistência continua local (`gestaobra:players:perfisPermissao`);
  nenhuma escrita em `user_roles` foi introduzida.

## Não escopo

- Sincronização de perfis com backend/RLS por papel (ARC-009).
- Herança/composição entre perfis.
- Import/export do catálogo.

## Validação

- `bunx tsgo --noEmit` — OK.
- Testes puros de `perfisPermissao` mantidos (slice-01).

## Estado

`PRO-028` encerrado na camada funcional local: perfis criáveis,
editáveis e aplicáveis no cadastro de usuário sem redigitar a matriz.
