# PRO-003.slice-06 — Trava server-side de competência fechada (DP)

**Onda:** 07 · **Achado:** PRO-003 · **Slice:** 06/n

## Entrega
- Função `public.dp_assert_competencia_aberta()` (SECURITY DEFINER,
  `search_path = public`) que consulta `dp_fechamento_competencia` e
  bloqueia mutação quando a competência (nova e antiga, no UPDATE) está
  fechada e o usuário **não** é GM (`current_is_gm()`).
- Triggers `BEFORE INSERT OR UPDATE OR DELETE`:
  - `trg_dp_holerite_comp_aberta` em `public.dp_holerite`
  - `trg_horas_extras_comp_aberta` em `public.horas_extras`
- Mensagem padronizada: `Competência YYYY-MM está fechada (desde ...)`
  com `ERRCODE = 'P0001'`, capturada pelo cliente como toast.

## Regras respeitadas
- Sem alterar RLS/policies existentes; a trava é ortogonal.
- GM segue com bypass (mesma política de `dp_fechar_competencia`).
- Warnings do linter são todos preexistentes; nenhum novo atribuível.

## Não escopo
- Slice-07: reconciliar fechamentos gravados em `localStorage` (uma
  migração pontual quando o usuário logar).
- Estender trava a outras tabelas DP (provisões, décimo terceiro) se
  aparecer demanda.

## Validação
- Migração aplicada com sucesso.
- Frontend não precisa mudar: `useDpFechamentoCompetenciaMerged`
  (slice-05) já propaga o erro do backend via toast.
