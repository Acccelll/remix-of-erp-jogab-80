# UX-005 · slice-02 — aria-label na toolbar do CommentEditor

## Escopo
Toolbar de `src/components/cards/CommentEditor.tsx`: 11 botões icon-only (bold, italic, strike, code, h2, h3, bullet list, ordered list, blockquote, link, mention, image) e demais controles com `title="..."`.

## Alterações
Todos os `title="X"` do arquivo receberam `aria-label="X"` espelhado (via script `re.sub` — 14 substituições, cobrindo os 11 botões da toolbar mais 3 controles auxiliares). O `title` foi mantido para tooltip visual; `aria-label` passa a ser a fonte primária de nome acessível para SR.

## Validação
- `tsgo --noEmit`: limpo.
- `rg 'size="icon"' src/components/cards/CommentEditor.tsx | wc -l` = 11 — todos agora com `aria-label`.
