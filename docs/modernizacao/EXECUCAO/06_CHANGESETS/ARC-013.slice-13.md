# ARC-013.slice-13 — Encapsular `cardRecursosRepo` em `useCards`

## Escopo
Migrar todos os consumidores diretos de `cardRecursosRepo` para hooks/queryFns canônicos em `@/hooks/useCards`.

## Alterações
- **`src/hooks/useCards.ts`**
  - Import: `cardRecursosRepo` (interno).
  - `cardsQueryFns`: `listAlertasRecursosPorCards`, `listKanbanRecursosPorCards`, `getRecursoByCard`.
  - Novos hooks: `useInsertCardRecurso`, `useUpdateCardRecursoByCard` (invalidam `cards`/`alertas-prazo`/`kanban-cards`/detalhe).
- **`src/hooks/useAlertasPrazo.ts`**: `listAlertasPorCards` → `cardsQueryFns.listAlertasRecursosPorCards`.
- **`src/components/cards/QuadroKanban.tsx`**: remove import direto; usa `cardsQueryFns.listKanbanRecursosPorCards`.
- **`src/components/cards/AdicionarRecursoDialog.tsx`**: remove import direto; `insert` via `useInsertCardRecurso`.
- **`src/components/cards/CardRecursoDialog.tsx`**: remove import direto; leitura via `cardsQueryFns.getRecursoByCard`, update via `useUpdateCardRecursoByCard`.

## Validação
- `tsgo --noEmit` limpo.
- `rg "cardRecursosRepo" src/` só retorna `useCards.ts` (canônico), `lib/repositories/cardsExtra.ts` (definição) e o teste de contrato `TST-002.f`.

## Semântica preservada
- `insert`/`updateByCard`/`getByCard`/`listKanbanPorCards` mantêm shape `{data,error}` do Supabase.
- `listAlertasPorCards` continua retornando `any[]` (throw em erro).
