# ARC-012.slice-01 — Mapeamento de consumidores `clientesRepo` / `insumosRepo`

## Escopo
Mapear os consumidores diretos restantes de `clientesRepo` e `insumosRepo` para definir a próxima consolidação por domínio, mantendo o padrão ARC-010/ARC-011: repositório como camada interna e páginas consumindo hooks TanStack Query.

## Achado
### `clientesRepo`
Consumidores diretos em runtime:

| Arquivo | Uso atual | Observação |
| --- | --- | --- |
| `src/hooks/financeiro/useObrasFinanceiro.ts` | `list()` | Hook financeiro local duplica leitura de clientes. |
| `src/components/obra/EditObraDialog.tsx` | `list()` | Query local com chave literal `clientes-edit-obra`. |
| `src/pages/financeiro/FinObras.tsx` | `list()` | Query local com chave literal `clientes`. |
| `src/pages/financeiro/FinClientes.tsx` | `list()`, `create()`, `update()`, `countObrasVinculadas()`, `remove()` | CRUD principal financeiro; exige mutations e invalidação centralizada. |
| `src/pages/financeiro/FinFluxo.tsx` | `listIdNome()` | Leitura resumida para filtros de fluxo. |

### `insumosRepo`
Consumidores diretos em runtime:

| Arquivo | Uso atual | Observação |
| --- | --- | --- |
| `src/hooks/useOrcamento.ts` | `listPrecos()` | Já encapsula leitura em `useInsumosPrecos()`, mas ainda importa o repo. |
| `src/pages/suprimentos/Insumos.tsx` | `listCompleto()`, `create()`, `update()`, `toggleAtivo()` | CRUD principal; candidato mais direto ao padrão ARC-011. |
| `src/pages/suprimentos/Estoque.tsx` | `listAtivosBasico()` | Leitura auxiliar para filtros e transferência. |
| `src/pages/suprimentos/CurvaABC.tsx` | `listResumoPrecos()` | Leitura auxiliar para cálculo ABC. |
| `src/pages/suprimentos/Composicoes.tsx` | `listAtivos()` | Leitura auxiliar para cálculo de composição. |

## Decisão
Priorizar `insumosRepo` no próximo slice, porque ainda não possui hook canônico de domínio e concentra um CRUD isolado com leituras auxiliares bem delimitadas. `clientesRepo` será tratado depois com mais cautela, pois já existe `src/hooks/useClientes.ts` ligado ao contexto/CRM e há risco de misturar shapes de dados do financeiro.

## Validação
- `rg "import \\{ clientesRepo \\}|clientesRepo\\.|import \\{ insumosRepo \\}|insumosRepo\\." src --glob '!**/__tests__/**'` usado para consolidar o mapa acima.
- Sem alteração de runtime neste slice.
