# ARC-013 · slice-04 — Migração dos consumidores restantes de `requisicoesRepo`

**Onda:** 3 (Arquitetura)  
**Achado:** ARC-013 (repositórios acoplados diretamente às páginas)  
**Escopo:** eliminar os 3 pontos de acesso direto a `requisicoesRepo` fora do hook canônico.

## Alterações

1. **`src/pages/suprimentos/Cotacoes.tsx`**
   - Import `requisicoesRepo` → `useUpdateRequisicaoStatus`.
   - `criarCotacao`: `requisicoesRepo.updateStatus(...)` → `updateReqStatusMut.mutateAsync({ id, status: "cotando" })`.

2. **`src/pages/suprimentos/OrdensCompra.tsx`**
   - Import `requisicoesRepo` → `useRequisicoesAll`.
   - `reqsQuery = useRequisicoesAll("id,obra_id,orcamento_item_id,quantidade,observacao,status")`; `reqs` sincronizado via `useEffect(reqsQuery.data)`.
   - `load()` remove entrada de `requisicoesRepo.listAll(...)` do `Promise.all` e passa a chamar `reqsQuery.refetch()` em paralelo com os demais fetches.

3. **`src/pages/planejamento/Restricoes.tsx`**
   - Import `requisicoesRepo` → `useRequisicoesResumoObra`.
   - `reqsQuery = useRequisicoesResumoObra(500)`; `reqs` sincronizado via `useEffect`.
   - `load()`: remove `requisicoesRepo.listResumoObra(500)` do `Promise.all` (junto com o `requisicoesRes` do check de erros) e adiciona `reqsQuery.refetch()`.

## Validação

- `rg "requisicoesRepo" src/pages src/components src/hooks` → apenas ocorrências dentro do hook canônico `src/hooks/useRequisicoes.ts`.
- `bunx tsgo --noEmit` → limpo.
- Semântica preservada: as leituras rodam via TanStack Query com invalidação centralizada (`requisicoesKeys.all`), e o botão de refresh (`load()`) ainda dispara refetch das requisições em paralelo.
