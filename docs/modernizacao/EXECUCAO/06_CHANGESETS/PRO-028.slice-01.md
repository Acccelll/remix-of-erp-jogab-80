# PRO-028.slice-01 — Perfis reutilizáveis de permissões (local)

**Onda:** 07 · **Achado:** PRO-028 (GM: sem perfis/papéis reutilizáveis)  
**Escopo:** base local para definir perfis de acesso e aplicá-los a usuários.

## Contexto

A matriz de acessos hoje é preenchida usuário a usuário. Não existe um
"papel" reutilizável (ex.: "Encarregado de Obra", "Compras Sênior"),
o que gera divergências e dificulta onboarding.

## Entrega

- `src/lib/players/perfisPermissao.ts`: tipos e regras puras
  (`acessosVazios`, `normalizarAcessos`, `validarPerfil`, `criarPerfil`,
  `perfilAPartirDePlayer`, `aplicarPerfilEmPlayer` com modo
  `substituir` / `mesclar` conservador que nunca rebaixa acesso).
- `src/hooks/usePerfisPermissao.ts`: CRUD com persistência local via
  chave canônica `gestaobra:players:perfisPermissao`.
- Nova chave em `STORAGE_KEYS.perfisPermissao`.
- Testes cobrindo validação, normalização, aplicação e mesclagem.

## Não escopo

- UI de gestão dos perfis e integração no cadastro de usuário
  (slice-02).
- Sincronização com backend (`user_roles`) e RLS por papel.
- Herança/composição entre perfis.

## Validação

- `bunx vitest run src/lib/players/__tests__/perfisPermissao.test.ts` — verde.
- `bunx tsgo --noEmit` — OK.

## Estado

`PRO-028` iniciado com base de dados e regras. Aplicação real na tela
de usuários fica para `PRO-028.slice-02`.
