# PRO-012 · slice-11 — Export dedicado do histórico de auditorias XLSX

## Escopo

Permitir baixar o histórico completo de auditorias de importação
(`auditoriasImportacao[]`, slice-10) como um arquivo XLSX independente do
export da contagem (slice-07). Cada importação vira uma aba própria com o
detalhamento das linhas ignoradas; um "Resumo" consolida todas.

## Alterações

### `src/pages/suprimentos/ContagensCiclicas.tsx`
- Nova função `exportarHistoricoAuditorias(c: ContagemCiclica)`:
  - Ordena os registros por `importadoEm` (mais antigo primeiro).
  - Aba `Resumo`: uma linha por importação com metadados e contadores
    (linhas / válidas / aplicados / divergentes / sem divergência /
    sem alteração / ignoradas).
  - Uma aba por importação (`imp_NN_<timestamp>`) com as linhas ignoradas
    (linha, código, motivo); se não houver, registra uma linha "sem linhas
    ignoradas" para manter a aba auditável.
  - Nome do arquivo: `auditorias_<local>_<data>.xlsx`.
  - Deduplicação/truncamento dos nomes de aba respeitando o limite de 31
    caracteres do Excel.
- Botão "Exportar histórico" no cabeçalho da seção "Histórico de
  importações XLSX" do diálogo de execução, visível apenas quando há pelo
  menos um registro.

## Contrato de execução

- Escopo restrito a `PRO-012`.
- Sem alterações no lib de contagens, no repositório ou no schema — apenas
  leitura do campo já persistido na slice-10.
- Sem chamadas à Cloud; export 100 % client-side via `xlsx`.

## Validação

- `bunx tsgo --noEmit` sem erros novos.
- Botão só aparece quando `auditoriasImportacao.length > 0`; export gera
  toast de aviso se, por corrida, a lista estiver vazia.
