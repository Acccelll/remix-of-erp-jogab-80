# PRO-012 · slice-26 — Persistência de sort e filtro em localStorage

## Escopo
Manter entre sessões as preferências da tabela de contagens cíclicas:
ordenação por tendência (`sortIgn`) e filtro "Somente em piora"
(`apenasPiora`).

## Alterações
- `src/pages/suprimentos/ContagensCiclicas.tsx`
  - Import de `loadLocal` de `@/lib/utils/local-storage`.
  - Chaves estáveis: `contagens-ciclicas:sortIgn`, `contagens-ciclicas:apenasPiora`.
  - Estados inicializados via `loadLocal(key, fallback)` (fallback = estado
    prévio: `null` para sort, `false` para filtro).
  - Dois `useEffect` gravam JSON no `localStorage` a cada alteração, com
    `try/catch` para tolerar quota/SSR.

## Contrato de execução
- UI-only, sem Cloud/RLS/schema. Persistência puramente local, chave
  namespaceada pela tela.

## Validação
- `bunx tsgo --noEmit` sem erros.
- Manual: aplicar sort Δ desc + filtro ligado, recarregar a página — a
  tabela volta com as mesmas preferências.
