# PRO-030 · slice-03 — Categoria "Snapshot TOTVS antigo"

**Onda:** 07 · **Achado:** PRO-030 · **Depende de:** slice-02.

## Contexto
Slice-01 previa "snapshot velho" como próxima categoria natural do catálogo. A fonte canônica já existe (`fetchSnapshotAtivo` do módulo TOTVS, usado hoje só pelo alerta local em `SnapshotAgeAlert`). Este slice reaproveita a mesma fonte para popular o sino global, respeitando permissão financeira e preferências.

## Entrega
- `src/hooks/useSnapshotVelho.ts` (novo): hook puro sobre `useQuery(["snapshot_ativo_age"], fetchSnapshotAtivo)`. Retorna `null` quando desabilitado, sem snapshot, ou idade < `warnDays` (3). Caso contrário, `{ status: 'aviso' | 'critico', ageDays, importadoEm }` com `critico` acima de `errorDays` (7). Mesmo `queryKey` do `SnapshotAgeAlert` — não duplica requisição.
- `src/hooks/useNotifPreferencias.ts`: nova categoria `snapshot_velho` em `NotifCategoriaId` e `NOTIF_CATEGORIAS`.
- `src/components/layout/NotificationBell.tsx`:
  - Consome `useSnapshotVelho(canSeeFin && isVisivel("snapshot_velho"))`.
  - Nova seção após "Importação TOTVS" com badge de idade (`Xd`), variante `destructive` em `crítico`, link para `/financeiro/importar`.
  - Contribui para o `totalBadge` global.

## Não escopo
- Preferências por usuário no backend (segue local, D-8).
- Snapshots operacionais fora de Financeiro (obras/contratos) — sem fonte canônica hoje; entra em achado próprio quando definido.
- Não altera o `SnapshotAgeAlert` local; ambos coexistem (contexto de tela × sino global).

## Validação
- `bunx tsgo --noEmit` limpo.
- Fluxo manual: ocultar "Snapshot TOTVS antigo" nas Preferências remove a seção e desconta do badge; reativar restaura sem recarregar.
