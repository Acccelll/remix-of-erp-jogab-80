# ARC-013 · Slice 17 — Encapsular `cardMembrosRepo` em `useCards`

## Escopo
Migrar leituras/mutações de `cardMembrosRepo` para hooks/queryFns canônicos em `src/hooks/useCards.ts`, removendo o import direto em `CardGenericoDialog`.

## Alterações
1. **`src/hooks/useCards.ts`**
   - Import interno de `cardMembrosRepo`.
   - `cardsKeys.membros(cardId)` (chave `["card-membros", cardId]`).
   - `cardsQueryFns.listCardMembroUserIds(cardId)` → retorna `string[]` já projetado.
   - Mutations: `useInsertCardMembro`, `useRemoveCardMembro`, `useRemoveCardMembrosByCard`.
     Todas invalidam `cardsKeys.all/alertasPrazo/kanban/detail` via `invalidateAllCards` + `cardsKeys.membros`.

2. **`src/components/cards/CardGenericoDialog.tsx`**
   - Remove `cardMembrosRepo` do import de `cardsExtra`.
   - Import de `useInsertCardMembro`, `useRemoveCardMembro`, `useRemoveCardMembrosByCard`.
   - `useQuery` de membros usa `cardsKeys.membros` + `cardsQueryFns.listCardMembroUserIds`.
   - `limparDadosSecao("membros")` usa `removeCardMembrosByCardMut.mutateAsync`.
   - `addMembro`/`removeMembro` usam as mutations canônicas (assinatura `{ cardId, userId }`).

## Validação
- `tsgo --noEmit`: limpo.
- `rg cardMembrosRepo src`: retorna apenas `useCards.ts` (canônico) e o teste de contrato (`repositories-contrato-c.test.ts`), preservado.
