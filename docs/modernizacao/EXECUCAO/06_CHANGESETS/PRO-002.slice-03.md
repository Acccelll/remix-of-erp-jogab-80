# PRO-002 · slice-03 — Ações rápidas de follow-up no NotificationBell

**Onda:** 07 · CRM · **Prioridade:** P2 · **Marco:** M11

## Contexto
As duas primeiras slices tornaram o follow-up visível (perfil + lista + sino).
Ainda era preciso sair do sino para adiar ou concluir uma tarefa, quebrando o
fluxo do usuário que só quer "empurrar 3 dias" ou marcar como resolvido.

## Entrega
- `src/hooks/useCrmTarefas.ts` — novo `adiar(id, dias)`:
  - Só afeta tarefas `aberta`.
  - Se a tarefa está vencida, adia a partir de hoje; senão, a partir da data
    atual (evita "adiar" para o passado).
  - Persiste via `save()` disparando o mesmo evento do padrão do hook.
- `src/components/layout/NotificationBell.tsx`:
  - Consome `alternar` e `adiar` do hook.
  - Cada item de "Follow-ups CRM" recebe barra de ações rápidas: **+1d / +3d /
    +7d** e **✓ concluir**. Os botões ficam fora do `<Link>` para não navegar
    quando clicados.

## Não escopo
- Não altera persistência nem estrutura das tarefas.
- Não introduz undo/toast (a lista se atualiza sozinha; concluir sai da fila).
- Não adiciona snooze com janela custom além dos três presets.

## Validação
- `bunx tsgo --noEmit` limpo.
- `bunx vitest run src/hooks/__tests__/useCrmTarefas.test.ts` → 2/2 verdes.
