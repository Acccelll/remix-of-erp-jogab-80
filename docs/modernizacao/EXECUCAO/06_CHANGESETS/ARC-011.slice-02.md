# ARC-011.slice-02 — `useFornecedoresCompleto` + mutações; página `Fornecedores` migrada

## Escopo
Completar a consolidação de Fornecedores como domínio TanStack Query: expor `useFornecedoresCompleto()`, `useCreateFornecedor()` e `useUpdateFornecedor()`; migrar a página CRUD para consumo via hooks e remover o `load()` imperativo.

## Alterações
- `src/hooks/useFornecedores.ts`: adiciona query `useFornecedoresCompleto()` (chave `["fornecedores","completo"]`) e mutations `useCreateFornecedor`/`useUpdateFornecedor` com `onSettled` invalidando as três chaves (`completo`, `resumo`, `resumo-ativos`). Toast de erro centralizado.
- `src/pages/suprimentos/Fornecedores.tsx`: substitui `useState<Fornecedor[]> + useEffect(load)` por `useFornecedoresCompleto()`. `handleSave` passa a chamar `createMut.mutateAsync` / `updateMut.mutateAsync`; `saving` deriva de `isPending`. Remove import direto de `fornecedoresRepo`.

## Validação
- `tsgo --noEmit` limpo.
- `rg "fornecedoresRepo\." src/ | grep -v __tests__ | grep -v hooks/useFornecedores` → zero ocorrências. Repositório permanece apenas como camada interna consumida pelo hook.
