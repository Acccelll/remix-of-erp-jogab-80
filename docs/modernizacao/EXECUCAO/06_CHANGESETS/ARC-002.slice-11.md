# ARC-002 · slice-11 — Migração de `obras`/`contratos` para contexts de domínio (batch 1)

**Onda:** 6 · **Status:** ✅ concluído · **Typecheck:** `tsgo` verde

## Contexto

Os consumers reais das mobilizações já vivem em contexts de domínio
(`useColaboradoresContext`, `usePatrimoniosContext`, `useContratosContext`,
`useVeiculosContext`). Portanto, migrá-los para o `MobilizacoesPendentesContext`
cross-domínio seria regressão. O slice reorienta a limpeza para o alvo maior:
reduzir os 39 consumers de `useApp()` que ainda leem `obras`/`contratos` que já
existem em contexts de domínio.

## Entregue (batch 1 — quadros principais)

- `src/pages/Board.tsx` — `obras` via `useObrasContext()`; `contratos` via `useContratosContext()`; `useApp()` mantido só para `hasAccess/currentPlayer`.
- `src/pages/QuadroPatrimonios.tsx` — `obras` via `useObrasContext()`; `useApp()` mantido para `hasAccess/currentPlayer`.
- `src/pages/QuadroContratos.tsx` — `obras` via `useObrasContext()`; `useApp()` mantido para `hasAccess/currentPlayer`.
