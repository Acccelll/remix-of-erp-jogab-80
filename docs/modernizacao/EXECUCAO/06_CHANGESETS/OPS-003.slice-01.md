# OPS-003.slice-01 — Logging estruturado + correlação (regra pura)

**Onda:** 7 · **Achado:** OPS-003 · **Tipo:** STD/REF · **Escopo:** LOTE (Plataforma)

## Problema

Hoje `logger.*` é wrapper fino sobre `console.*` com strings livres. Não
há campos estruturados, severidade padronizada como dado, nem
`correlationId` propagado entre cliente → backend → edge. Investigar um
incidente pós-fato é inviável na fronteira dupla (PHP + Supabase + edge).

## Alterações

`src/lib/observability/correlation.ts` (novo, `@module-kind pure`):
- `newCorrelationId(prefix?)` gera id url-safe curto usando WebCrypto.
- `withCorrelation(id, fn)` / `getCorrelationId()` empilham/desempilham
  o id corrente em LIFO síncrono (sem AsyncLocalStorage — não existe
  no browser; para async, captura-se e passa-se explícito).

`src/lib/observability/structured-logger.ts` (novo, `@module-kind pure`):
- `emit(severity, event, { correlationId?, fields? })` e helper
  `structured.{debug,info,warn,error}`.
- Formato canônico `{ ts, severity, event, correlationId?, fields? }`.
- `addSink(fn)` permite consumidores externos (console, Sentry
  breadcrumb, coletor — a serem plugados em `slice-02/03`).
- Sink defeituoso é isolado (`try/catch`) para não derrubar o caller.
- `Error` em `fields` é serializado como `{ name, message }`; demais
  valores best-effort via `JSON.parse(JSON.stringify(...))`.
- Correlation id: explícito > contexto corrente > `undefined`.

`src/lib/observability/__tests__/structured-logger.test.ts` (novo):
- 8 casos verdes cobrindo unicidade de id, LIFO, unwind com exceção,
  emissão de evento, herança de correlação, sobreposição explícita,
  serialização de `Error`, isolamento de sink defeituoso.

## Não escopo

- Não altera `src/lib/logger.ts` (compat mantida — mensagens livres
  continuam existindo).
- Não pluga sink real (Sentry/coletor) — fica para `slice-02`.
- Não instrumenta call-sites (auth, api, edges) — `slice-03..04`.
- Nada de I/O, DB, RLS ou schema.

## Validação

- `bunx vitest run src/lib/observability/__tests__/structured-logger.test.ts` → 8/8 verde.
- `bunx tsgo --noEmit` limpo.
