## 2. Regra de fixed point

- **FP-1.** Enquanto não houver intake formal GM/D-3 conforme R217'/R218'/R227', qualquer novo round documental derivado apenas de comando genérico é classificado como `META-ROUND` e não altera R229'.

- **FP-3.** Se um comando genérico não puder gerar `META-ROUND` sem duplicar papel canônico, a resposta correta é apenas o envelope R224' + snapshot R232', sem criar arquivo novo.
- **FP-4.** Nenhum `META-ROUND` cria ledger, preenche §5 de `D-3-SEC-002.md`, cria `GO-SEC-002-helpers-02-deploy-01.md`, altera `helpers-02.deploy-01`/`helpers-03.apply-01`, migra banco ou solicita segredo.
