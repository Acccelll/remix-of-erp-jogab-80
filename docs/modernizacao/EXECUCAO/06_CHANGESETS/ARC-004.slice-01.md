# ARC-004.slice-01 — Obras migradas para paradigma único (TanStack Query mutations)

**Onda:** 6 · **Achado:** ARC-004 (duas máquinas de estado servidor)

## Escopo
Primeira migração do CRUD imperativo (`api.create/update/remove` + `setState` local) para **mutations TanStack Query** com otimismo + rollback padronizado. Domínio-piloto: `obras` (isolado, poucos consumidores, provider próprio já em vigor).

## Mudanças
- **`src/hooks/useObras.ts`**: adiciona `useAddObra`, `useUpdateObra`, `useDeleteObra`. Todas seguem o padrão canônico:
  - `onMutate` → cancela queries, snapshot em `ctx.prev`, aplica otimismo em `setQueryData`.
  - `onError` → restaura `ctx.prev`, log + `toast.error`.
  - `onSettled` → `invalidateQueries` (garante convergência com servidor).
- **`src/contexts/ObrasContext.tsx`**: reescrito — consome `useObras().data` diretamente (fim do estado local paralelo) e expõe `addObra/updateObra/deleteObra` como fachadas finas sobre `mutateAsync`/`mutate`. Mantém assinatura pública (consumidores intactos).
- **`src/contexts/app/useObrasState.ts`**: **removido** — paradigma imperativo eliminado para o domínio.

## Convenção emergente (a replicar em slices seguintes)
1. Hook de domínio (`useXxx.ts`) exporta `useXxx` (query) + `useAddXxx/useUpdateXxx/useDeleteXxx` (mutations com `onMutate/onError/onSettled`).
2. `XxxStateProvider` (ou `XxxContext`) consome cache TanStack via `useXxx().data ?? []` e expõe CRUDs via fachadas `useCallback` sobre `mutateAsync`.
3. `useSyncQueryToState` + `useState` local **removidos** do domínio migrado.
4. `xxxLoaded` = `!queryEnabled || query.isSuccess` (inalterado).

## Validação
- `tsgo --noEmit` limpo.
- Assinatura pública `useObrasContext()` preservada — consumidores (`useApp()` bridge, telas) intactos.
