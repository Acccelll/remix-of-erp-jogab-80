# ARC-013 · slice-05 — Hook canônico de Ponto

**Onda:** 3 (Arquitetura)  
**Achado:** ARC-013 (repositórios acoplados diretamente às páginas)  
**Escopo:** centralizar leituras e importação de Ponto em `src/hooks/usePonto.ts`.

## Alterações

1. **`src/hooks/usePonto.ts`**
   - Novo ponto canônico para `pontoRepo`.
   - Leituras migradas para `queryKey(...)` registrado: `ponto_registros`, `homem_hora`, `custo_previsto`.
   - `staleTime: 30_000` nas leituras.
   - `useImportarPonto()` encapsula resolução de colaboradores/obras + persistência da importação e invalida `ponto_registros`/`homem_hora` ao concluir.

2. **`src/lib/ponto/pontoQueries.ts`**
   - Mantido como compat legado, reexportando o hook canônico.
   - Remove acesso direto próprio a `pontoRepo`.

3. **`src/pages/dp/PontoAnalise.tsx`**
   - Import `@/lib/ponto/pontoQueries` → `@/hooks/usePonto`.

4. **`src/pages/dp/HomemHora.tsx`**
   - Import `@/lib/ponto/pontoQueries` → `@/hooks/usePonto`.

5. **`src/pages/dp/PontoImportar.tsx`**
   - Remove import direto de `resolveColaboradores`, `resolveObras`, `importarPonto`.
   - Importação passa por `useImportarPonto().mutateAsync(...)`.
   - `saving` deriva de `isPending` da mutation.

## Validação

- Consumidores de tela de Ponto passam a usar `@/hooks/usePonto`.
- `pontoRepo` permanece encapsulado em `src/hooks/usePonto.ts` e na orquestração interna `src/lib/ponto/pontoRepo.ts`.

## Consumidores runtime restantes de `pontoRepo`

Restam apenas:

- `src/hooks/usePonto.ts` — hook canônico.
- `src/lib/ponto/pontoRepo.ts` — orquestração interna de importação (parse puro + regras + persistência delegada).
