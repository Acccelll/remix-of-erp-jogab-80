# ChangeSet UX-001 — Porta única de Suprimentos

**Onda:** 4 — Padronização  
**Status:** Concluído  
**Estratégia:** ISOLADA

## Problema

O módulo de Suprimentos tinha telas estruturantes acessíveis por URL direta,
Command Palette ou conhecimento prévio, mas sem porta clara de navegação:
`/suprimentos/insumos`, `/suprimentos/composicoes`, `/suprimentos/orcamento`,
`/suprimentos/curva-abc`, `/suprimentos/grupos-gestao` e Alçadas. A sidebar
também misturava processo operacional com configurações fragmentadas.

## Solução

### Novo hub `/suprimentos`

Criada porta única com abas para todo o módulo:

| Aba | Rota legada preservada |
| --- | --- |
| Compras | `/suprimentos/compras` |
| Produção | `/suprimentos/producao` |
| Requisições | `/suprimentos/requisicoes` |
| Cotações | `/suprimentos/cotacoes` |
| Ordens | `/suprimentos/ordens-compra` |
| Estoque | `/suprimentos/estoque`, `/suprimentos/estoque/saldos` |
| Recebimento | `/suprimentos/recebimento` |
| Fornecedores | `/suprimentos/fornecedores` |
| Insumos | `/suprimentos/insumos` |
| Composições | `/suprimentos/composicoes` |
| Orçamento | `/suprimentos/orcamento` |
| Curva ABC | `/suprimentos/curva-abc` |
| Alçadas | `/suprimentos/alcadas` |
| Grupos | `/suprimentos/grupos-gestao` |

As rotas antigas passam a redirecionar para `/suprimentos?tab=...`, mantendo
compatibilidade de favoritos e links internos sem deixar telas órfãs.

### Navegação

- Sidebar reduzida para um item principal: **Suprimentos**.
- Todas as telas internas continuam descobríveis pela Command Palette via
  `HIDDEN_NAV_ITEMS`.
- Breadcrumbs mantêm rótulos dos segmentos conhecidos.

## Fora de escopo

- Alterar regras de permissão por página.
- Reescrever as telas funcionais de Suprimentos.
- Unificar visual interno de formulários/tabelas; coberto por achados DS
  específicos.

## Validação

- `/suprimentos` abre a porta do módulo.
- URLs legadas redirecionam para a aba equivalente.
- Nenhuma rota de Suprimentos fica sem menu, hub ou Command Palette.

## Risco / Rollback

Baixo. A mudança reorganiza descoberta e roteamento; os componentes de cada
tela permanecem os mesmos. Rollback: voltar as rotas diretas em `App.tsx` e
restaurar os itens individuais de sidebar.
