## 2. Contrato dos novos gates

### 2.1 PC8 — Gerador `gen-tests-02.mjs --check`

- **Precondição de execução:** `.github/sec002-evidence/tests-02-gen-01/manifest.json` existe **e** contém `{ "applied": true }`.
- Se ausente ou `applied: false` → PC8 é **SKIP** (não conta como fail).
- Se aplicado, o verifier executa `node scripts/sec002/gen-tests-02.mjs --check` como subprocesso.
  - Exit `0` → PC8 verde.
  - Exit `1` → `E_WAVE2_PC8_DIFF` com lista das primeiras 10 linhas `DIFF <caminho> expected=... got=...`.
  - Exit `2` → `E_WAVE2_PC8_INPUT` (spec/CSV ausente ou malformado).
  - Exit `3` → `E_WAVE2_PC8_WRITE_GUARD` (violação de bloqueio de escrita do gerador).
- **Nunca** executa `gen-tests-02.mjs` sem `--check`. PC8 é read-only por construção.

### 2.2 PC9 — Runner `run-sec-002-tests.sh --json`

- **Precondição de execução:** `.github/sec002-evidence/tests-02-runner-01/manifest.json` existe **e** contém `{ "applied": true }` **e** env `SEC002_RUN_PC9=1` **e** `DATABASE_URL` definida.
- Se qualquer condição faltar → PC9 é **SKIP**.
- Se todas presentes, verifier executa `bash scripts/sec002/run-sec-002-tests.sh --json --batch all` capturando stdout.
  - Parse do JSON: `ok === true && totals.files === 315 && totals.fail === 0 && totals.timeout === 0` → PC9 verde.
  - Qualquer divergência → `E_WAVE2_PC9_RED` com sumário `{batch}: {ok}/{total} fail={n} timeout={n}` e primeiros 5 `failures[].test_id`.
  - Exit `2` do runner → `E_WAVE2_PC9_CONFIG`.
  - Exit `3` do runner → `E_WAVE2_PC9_WRITE_GUARD`.
- PC9 **jamais** é executado em CI sem `SEC002_RUN_PC9=1` explícito (evita ligar DB por acidente).
