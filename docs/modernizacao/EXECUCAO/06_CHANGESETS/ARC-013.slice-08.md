# ARC-013 · slice-08 — mutações `updateGrupoNegociacao*` via `useUpdateGrupoNegociacaoCards`

**Onda:** 6 (ARC-013)
**Escopo:** substituir chamadas diretas a `cardsRepo.updateGrupoNegociacao` /
`cardsRepo.updateGrupoNegociacaoIn` nos componentes consumidores pelo hook canônico
`useUpdateGrupoNegociacaoCards()` (`src/hooks/useCards.ts`).

## Alterações

- `src/components/cards/TabelaConsolidadaCompras.tsx`
  - Removidos `useQueryClient` e import direto de `cardsRepo`.
  - `atribuirGrupo` usa `useUpdateGrupoNegociacaoCards().mutateAsync({ ids, grupoId })`;
    invalidação de `alertas-prazo` / `kanban-cards` / `grupos-negociacao-cnt` passa
    a ser feita pelo `onSettled` do hook.

- `src/components/cards/QuadroKanban.tsx`
  - Adicionado hook `useUpdateGrupoNegociacaoCards()`.
  - `atribuirGrupo` deixa de chamar `cardsRepo.updateGrupoNegociacaoIn` e passa a
    usar `mutateAsync({ ids, grupoId })`. Toast de erro fica a cargo do hook.
  - `cardsRepo` permanece importado apenas para `listKanbanByIds` (leitura),
    a ser migrada em slice futuro.

## Validação

- `bunx tsgo --noEmit` — sem erros.
- Semântica preservada: ambos métodos do repositório eram equivalentes
  (`update grupo_negociacao_id where id in (...)`).
- Invalidação de cache: `useUpdateGrupoNegociacaoCards` já invalida
  `alertas-prazo`, `kanban-cards` e `grupos-negociacao-cnt`.
