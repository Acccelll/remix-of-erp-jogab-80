# ARC-002.slice-08 — PlayersContext (usuários do sistema)

**Onda:** 6 · **Prioridade:** P1 · **Tipo:** REF/MIGRAÇÃO
**Achado:** ARC-002 (god-context)

## Escopo

Oitavo slice da extração de subcontextos de domínio a partir de `AppContext`. Cria `PlayersContext` como fachada para o domínio de usuários (players), populado por `useApp()` sem mover estado real. Não altera `useAuth()` nem o pipeline de permissões.

## Mudanças materializadas

- Novo `src/contexts/PlayersContext.tsx` expondo `players`, `addPlayer`, `updatePlayer`, `deletePlayer` a partir de `useApp()`.
- `PlayersProvider` montado em `src/App.tsx` dentro de `FuncoesProvider`, mantendo a ordem `App → Colaboradores → Patrimonios → Veiculos → Contratos → Obras → Clientes → Funcoes → Players → Empresa`.
- Nenhum consumer migrado nesta etapa; contrato público de `useApp()` inalterado.

## Critérios preservados

- Sem alteração de UI, permissões, autenticação ou persistência.
- Estado real ainda vive em `AppProvider` via `usePlayersState`.
- Typecheck (`tsgo`) verde.

## Próximo

Migrar consumers reais de players (telas de GM/Admin, `GM.tsx`, `admin/Empresas.tsx` se aplicável) para `usePlayersContext()`.
