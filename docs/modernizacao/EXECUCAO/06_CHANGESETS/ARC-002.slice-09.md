# ARC-002.slice-09 — DocumentosContext (vencimentos)

**Onda:** 6 · **Prioridade:** P1 · **Tipo:** REF/MIGRAÇÃO
**Achado:** ARC-002 (god-context)

## Escopo

Nono slice da extração de subcontextos de domínio a partir de `AppContext`. Cria `DocumentosContext` como fachada para consultas de vencimentos de documentos, populado por `useApp()` sem mover cálculo real. Não altera regras de aviso, fallback virtual de férias, permissões ou persistência.

## Mudanças materializadas

- Novo `src/contexts/DocumentosContext.tsx` expondo `getExpiringDocuments` e `getAllExpiringDocuments` a partir de `useApp()`.
- `DocumentosProvider` montado em `src/App.tsx` dentro de `PlayersProvider`, mantendo a ordem `App → Colaboradores → Patrimonios → Veiculos → Contratos → Obras → Clientes → Funcoes → Players → Documentos → Empresa`.
- Nenhum consumer migrado nesta etapa; contrato público de `useApp()` inalterado.

## Critérios preservados

- Sem alteração de UI, filtros, vencimentos, férias ou persistência.
- Cálculo real continua em `useExpiringDocuments` dentro do `AppProvider`.
- Typecheck (`tsgo`) deve permanecer verde.

## Próximo

Migrar consumers reais de vencimentos (`Board.tsx`, `rh/ControleDocumentos.tsx`, `NotificationBell` via `useAppRead` se aplicável) para `useDocumentosContext()`.
