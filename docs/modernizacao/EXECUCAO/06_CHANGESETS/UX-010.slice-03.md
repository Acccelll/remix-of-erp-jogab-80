# UX-010 · slice-03 — Consolidação da escala executiva em classes utilitárias

**Onda:** 07 · **Achado:** UX-010 · **Depende de:** slice-01 (CRM Dashboard) e slice-02 (EVM + GM).

## Contexto

Os dois pilotos confirmaram a mesma escala executiva (rótulo `xs`
uppercase muted, valor `text-lg/2xl` semibold tabular). Este slice
promove essa escala a classes semânticas em `index.css` e substitui
as ocorrências ajustadas, evitando drift entre telas.

## Entrega

- `src/index.css` (`@layer components`) — quatro novas classes:
  - `.text-metric` → `text-2xl font-semibold tabular-nums leading-tight`
    (KPI primário de dashboard).
  - `.text-metric-sm` → `text-lg font-semibold tabular-nums leading-tight`
    (KPI secundário em cards adensados, ex.: `Stat` do EVM).
  - `.text-metric-label` → `text-xs uppercase tracking-wide text-muted-foreground font-medium`.
  - `.text-metric-hint` → `text-sm text-muted-foreground`.
- `src/pages/crm/CRMDashboard.tsx` — `Stat.value` usa `text-metric`;
  `Stat.hint` usa `text-metric-hint`.
- `src/components/obra/DesempenhoTab.tsx` — `Stat.label` usa
  `text-metric-label`; `Stat.valor` usa `text-metric-sm` (mantém
  `color` tonal).

## Escopo consciente

- Não converte demais telas em massa neste slice — as classes ficam
  disponíveis para adoção incremental sem regressão.
- Não redefine tipografia base do Tailwind; são utilitários
  compostos via `@apply`.
- Não altera hierarquia visual dos dois pilotos: as classes
  reproduzem o resultado dos slices 01/02.

## Validação

- `bunx tsgo --noEmit` limpo.
- Diff visual esperado: idêntico aos slices 01/02 (as classes
  substituem exatamente os mesmos utilitários agrupados).
