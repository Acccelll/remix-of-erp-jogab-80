# Changeset BIZ-002.b — Extração de parse/domínio puro em Trello e BMS

**Achado:** BIZ-002 — Lib bimodal pura x impura sem convenção (Etapa 6)  
**Onda:** 3  
**Lote:** B (extração de lógica pura)

## Objetivo

Separar domínio puro de efeitos nos dois pontos mistos previstos no lote B:
`cards/trello-import.ts` e `bms/boletim.ts`.

## Mudanças

### Trello

- Criado `src/lib/cards/trello-parse.ts` como módulo `pure` contendo:
  - tipos do JSON Trello;
  - normalização de cores;
  - sanitização de datas;
  - fallback de listas ausentes;
  - conjunto de eventos de atividade.
- `src/lib/cards/trello-import.ts` permanece `io`, agora consumindo o domínio puro extraído e mantendo a persistência da importação.
- `src/lib/trello/parseTrelloCsv.ts` passou a depender dos tipos puros de `trello-parse`, evitando acoplamento com o importador I/O.

### BMS

- `src/lib/bms/boletim.ts` permanece `pure`, apenas com totais, Excel e PDF gerados a partir dos dados recebidos.
- Criado `src/lib/bms/boletim-storage.ts` como módulo `io` para o upload opcional do boletim.
- Call-sites de obra e medições importam `uploadBoletim` do módulo I/O explícito.

## Verificação

- `bash scripts/verify-lib-purity.sh` → OK.
- `rg "auth\.getUser|storage\.from|from ['\"]@/integrations/supabase" src/lib/bms/boletim.ts src/lib/cards/trello-parse.ts` → zero ocorrências.
