# PRO-032 · slice-04 — Drill-down por mês no painel M12

## Escopo
Clicar em uma barra do gráfico "Movimentação mensal" abre um diálogo com a lista de contratos que entraram como *novos* e como *encerrados* naquele mês.

## Mudanças
- `src/lib/contratos/serie-mensal.ts`: nova função pura `contratosDoMes(contratos, chave)` retornando `{ novos, encerrados }` para o bucket `yyyy-MM` (mesma regra de datas usada em `serieContratosMensal`).
- `src/lib/contratos/__tests__/serie-mensal.test.ts`: cobre `contratosDoMes` (novos, encerrados via `termino` e mês sem encerramentos).
- `src/components/contratos/ContratosOverview.tsx`:
  - Estado `mesAberto: { chave, rotulo } | null` e `detalhe = contratosDoMes(...)` memoizado.
  - `BarChart.onClick` captura `activePayload[0].payload` (com `chave`+`rotulo`) e abre `Dialog` shadcn.
  - Diálogo mostra duas colunas com `ScrollArea` — Novos e Encerrados — listando `locacaoServico`.

## Fora do escopo
- Navegação para a ficha do contrato a partir da lista (candidato slice-05).
- Filtros adicionais dentro do diálogo.

## Validação
- `bunx tsgo --noEmit` limpo.
- `vitest run serie-mensal.test.ts` — 3/3 passando.
