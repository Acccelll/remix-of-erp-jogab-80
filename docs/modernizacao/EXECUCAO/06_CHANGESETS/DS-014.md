# Catálogo da Biblioteca de UI (GestãObra)

**Onda:** 4 — Padronização · **Achado:** DS-014
**Base:** shadcn/ui + Radix + TailwindCSS 3 + `class-variance-authority`.
**Regra de ouro:** SEMPRE reutilize daqui. Não recrie primitivos.
Tokens (cores, radius, sombras) vêm de `src/index.css` — nunca use `text-white`, `bg-black`, `bg-[#hex]`.

---

## 1. Como consumir

```tsx
import { Button } from "@/components/ui/button";
import { Dialog, DialogContent } from "@/components/ui/dialog";
```

Padrões:
- **Nunca edite** `client.ts`/`types.ts` do backend.
- **Nunca hardcode cor** — use variantes ou tokens semânticos (`bg-primary`, `text-muted-foreground`).
- **Sempre** teste com tema claro/escuro.

## 3. Componentes GestãObra (obrigatórios)

Substituem primitivos crus em contextos específicos.

| Componente | Arquivo | Quando usar | Notas |
| --- | --- | --- | --- |
| `Dialog` + prop `size` | `dialog.tsx` | Todo modal. | Escala oficial DS-015: `xs·sm·md·lg·xl·2xl·3xl·full`. Não use `max-w-*` inline. |
| `FilterBar` | `filter-bar.tsx` | Barra de busca/filtro de lista. | Slots: `search`, `children` (selects), `actions`, `onClear`. |
| `DataTable` | `data-table.tsx` | Toda lista tabular navegável. | Baseada em tanstack `ColumnDef`. Combina com `EmptyState`, `PageLoading`, `Pagination`. Ver DS-009. |
| `SortHeader` | `sort-header.tsx` | Cabeçalhos com ordenação. | Usar em `columns` do `DataTable`. |
| `Chart` | `chart.tsx` | Toda visualização. | Wrapper único sobre Recharts (DS-008). Nunca importe Recharts direto em página. |
| `MoneyInput` / `PercentInput` / `CnpjInput` / `ChipsNumberInput` | idem | Entradas de domínio. | Formatação e máscara centralizadas. |
| `BusyOverlay` | `busy-overlay.tsx` | Bloqueio temporário durante ação. | Prefira `Skeleton`/`PageLoading` para primeira carga. |

## 5. Convenções de composição

- **Formulário curto (≤6 campos):** `Dialog size="sm|md"` + `Label`/`Input`.
- **Formulário grande / wizard:** `Dialog size="xl|2xl"` com abas (`Tabs`).
- **Lista principal:** `PageHeader` → `FilterBar` → `DataTable` (+ `Pagination`).
- **Detalhe:** `Sheet` (contexto) ou rota dedicada (perfil).
- **Ação destrutiva:** `AlertDialog` (não `confirm` nativo).
- **Feedback pós-ação:** `toast.success` / `toast.error`.
- **Ícones:** `lucide-react` — tamanho `h-4 w-4` inline / `h-5 w-5` botões.
- **Espaçamento:** `gap-2` (denso), `gap-4` (padrão), `gap-6` (seções).

---

## 6. Decisão sobre criar novo componente

Antes de criar algo em `src/components/ui/`:

1. Existe primitivo shadcn cobrindo? Use.
2. Existe wrapper GestãObra? Use.
3. Precisa de nova primitiva reutilizável em ≥3 telas? Adicione em `ui/`, registre aqui e abra changeset `DS-*`.
4. Uso pontual? Componente local à página/feature.
