# ARC-004.slice-06 — `contratos` no paradigma único TanStack Query

**Onda:** 6 · **Contrato:** ARC-002 / ARC-004

## Escopo
Alinhar `contratos` ao padrão de `clientes`/`colaboradores`/`patrimonios`/`veiculos`:
leitura + mutações otimistas via TanStack Query, sem `useState` paralelo.

## Alterações
- `src/hooks/useContratos.ts` — adicionadas mutations `useAddContrato`,
  `useUpdateContrato`, `useDeleteContrato` (padrão canônico
  `onMutate` snapshot → `onError` restore → `onSettled` invalidate).
- `src/contexts/contratos/ContratosStateContext.tsx` — reescrito:
  `contratos = useContratos().data ?? []`; `setContratos` como wrapper
  `qc.setQueryData`; CRUDs delegam às mutations; `currentPlayerRef` simplificado;
  remove `useSyncQueryToState` e `useContratosState`.
- `src/contexts/app/useContratosState.ts` — **removido**.

## Validação
- `tsgo --noEmit` limpo.
- Assinatura pública `useContratosStateContext()` preservada.
