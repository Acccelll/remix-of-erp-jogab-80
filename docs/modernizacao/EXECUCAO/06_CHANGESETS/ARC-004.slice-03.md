# ARC-004.slice-03 — Colaboradores migrados para paradigma único (TanStack Query mutations)

**Onda:** 6 · **Achado:** ARC-004

## Escopo
Migra `colaboradores` do CRUD imperativo para mutations TanStack Query.

## Mudanças
- **`src/hooks/useColaboradores.ts`**: adiciona `useAddColaborador`, `useDeleteColaborador` (padrão canônico). Payload de `addColaborador` recebe o objeto já montado — regra de negócio (defaults de docs/histórico) permanece no provider por depender de `funcoes`/`currentPlayer`.
- **`src/contexts/colaboradores/ColaboradoresStateContext.tsx`**: reescrito — `colaboradores = useColaboradores().data ?? []`; `setColaboradores` vira wrapper `qc.setQueryData` compatível com `React.Dispatch<SetStateAction>` (preserva contrato de `useMobilizacoes`/`useUpdateColaborador`, que ainda escrevem no cache diretamente).
- **`src/contexts/app/useColaboradoresState.ts`**: removido.

## Nota
`updateColaborador` (lógica complexa de docs) segue em `useUpdateColaborador.ts`, agora escrevendo via wrapper — sem regressão. Migração para mutation dedicada fica prevista quando fizermos slice específico de "documentos do colaborador".

## Validação
- `tsgo --noEmit` limpo. Assinatura pública preservada.
