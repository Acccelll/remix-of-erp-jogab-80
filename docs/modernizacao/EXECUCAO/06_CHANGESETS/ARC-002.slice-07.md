# ARC-002.slice-07 — FuncoesContext (funções + tipos de documento)

**Onda:** 6 · **Prioridade:** P1 · **Tipo:** REF/MIGRAÇÃO
**Achado:** ARC-002 (god-context)

## Escopo

Sétimo slice da extração de subcontextos de domínio a partir de `AppContext`. Cria `FuncoesContext` como fachada única para o domínio de funções e tipos de documento (fortemente acoplados via NRs obrigatórias e vencimento), populado por `useApp()` sem mover estado real.

## Mudanças materializadas

- Novo `src/contexts/FuncoesContext.tsx` expondo `funcoes`, `addFuncao`, `updateFuncao`, `documentosTipo`, `addDocumentoTipo`, `updateDocumentoTipo`, `deleteDocumentoTipo` a partir de `useApp()`.
- `FuncoesProvider` montado em `src/App.tsx` dentro de `ClientesProvider`, mantendo a ordem `App → Colaboradores → Patrimonios → Veiculos → Contratos → Obras → Clientes → Funcoes → Empresa`.
- Nenhum consumer migrado nesta etapa; contrato público de `useApp()` inalterado.

## Critérios preservados

- Sem alteração de UI, NRs, vencimentos ou persistência.
- Estado real ainda vive em `AppProvider`.
- Typecheck (`tsgo`) verde.

## Próximo

Migrar consumers reais (`rh/Funcoes.tsx`, `rh/ControleDocumentos.tsx`, `rh/EmployeeFormDialog`, `rh/EmployeeProfileDialog`, `rh/EmployeeDPDialog`) para `useFuncoesContext()`, mantendo `useApp()` apenas para catálogos/permissões residuais.
