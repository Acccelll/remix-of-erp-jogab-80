# PRO-031 · slice-10 — Dados institucionais no cabeçalho do BMS

**Onda:** 07 · **Achado:** PRO-031 (parametrização por empresa)
**Depende de:** PRO-031.slice-02 (dialog de parametrização), slice-07 (logo BMS).

## Contexto
A parametrização por empresa cobria logo + numerações. Faltava expor os
campos institucionais (razão social, CNPJ, endereço, contato) e consumi-los
nos cabeçalhos formais.

## Entrega
- `src/lib/empresa/parametrizacao.ts`
  - Nova interface `DadosInstitucionaisEmpresa` (razaoSocial, cnpj,
    endereco, telefone, email, site) — todos opcionais.
  - `EmpresaParametrizacao.institucional?` (backward-compatible — omissão
    equivale ao estado anterior).
  - `empresaParametrizacaoRepo.setInstitucional(empresaId, dados)`.
  - Helper `getInstitucionalHeaderLines(empresaId, fallback?)`: devolve até
    duas linhas curtas (`"Razão · CNPJ …"` e `"Endereço · Tel · E-mail · Site"`)
    prontas para cabeçalho, aceitando fallback (ex.: `empresas.razao_social`).
- `src/components/admin/EmpresaParametrizacaoDialog.tsx`
  - Nova seção “Dados institucionais” com os 6 campos, gravados em
    `state.institucional`. Persistência via `Salvar` continua usando
    `empresaParametrizacaoRepo.save`.
- `src/lib/bms/boletim.ts`
  - `BoletimPdfOpts.institucionalLines?: string[]`. Quando presente,
    renderiza linhas centralizadas em cinza sob o título, e o cursor do
    header dinâmico (`y`) é deslocado para não colidir.
- `src/components/obra-detalhe/MedicoesTab.tsx`
  - `BoletimDialog.baixarPdf` passa `institucionalLines =
    getInstitucionalHeaderLines(empresaId)` junto do `logoDataUrl`.

## Escopo consciente
- Consumidor único nesta slice: PDF do BMS. RDO/Suprimentos/Obras/Inspeção
  ficam para slice-11 (mesma helper, mesmo padrão).
- Sem migração: dados institucionais são opcionais e persistidos apenas
  localmente (mesmo repo `localStorage`).
- Sem integração com `empresas.razao_social` do backend — o helper aceita
  fallback, mas ainda não é acionado (dependeria de query adicional).

## Validação
- `bunx tsgo --noEmit` — limpo.
- Suíte de numeração continua verde (4/4).
