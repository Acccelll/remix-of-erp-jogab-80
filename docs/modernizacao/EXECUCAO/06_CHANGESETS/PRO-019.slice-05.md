# PRO-019 · slice-05 — Silenciar alertas de contrato por 7 dias

**Onda:** 08 · **Achado:** PRO-019 residual / M12 · **Depende de:** `PRO-019.slice-04`.

## Contexto

Alertas críticos ficavam permanentemente no banner/sino após reconhecidos.
Sem forma de "esconder até resolver", o usuário perdia sinal de novos itens.

## Entrega

- **`src/lib/storage/keys.ts`**
  - Nova chave `contratosAlertaSilenciados` (`gestaobra:contratos:alertaSilenciados`).
- **`src/hooks/useContratoAlertaSilencio.ts`** (novo)
  - `SilenciadosMap` = `{ "${contratoId}:${tipo}": ISOdate }` em localStorage.
  - API: `silenciarAte`, `reativar`, `estaSilenciado`, `filtrar`.
  - Escuta evento `storage` para sincronizar entre abas.
  - Datas passadas são ignoradas — alerta volta a aparecer automaticamente.
- **`src/components/contratos/ContratosAlertaBanner.tsx`**
  - Aplica `filtrar` sobre `useContratosVencendo`.
  - Botão `BellOff · 7d` em cada linha registra silêncio por 7 dias.
- **`src/components/layout/NotificationBell.tsx`**
  - Aplica `filtrar` na lista consumida do hook; sino respeita silenciamentos.

## Não escopo

- UI de gestão/limpeza dos silenciados (previsto para slice-06).
- Persistência remota; escopo permanece local ao navegador (M12).
- Silêncio permanente ou por outros intervalos além de 7 dias.

## Validação

- `bunx tsgo --noEmit` limpo.
