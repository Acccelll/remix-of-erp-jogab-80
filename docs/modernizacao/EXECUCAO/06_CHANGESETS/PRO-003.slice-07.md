# PRO-003.slice-07 — Reconciliação local → backend dos fechamentos DP

**Onda:** 07 · **Achado:** PRO-003 · **Slice:** 07/n

## Entrega
- `src/hooks/useDpFechamentoReconciliacao.ts`: replica fechamentos
  gravados em `localStorage` (slices 01–03) para
  `dp_fechamento_competencia` via RPC `dp_fechar_competencia`, uma
  única vez por navegador (flag `gestaobra:dp:fechamentosCompetencia:reconciliadoEm`).
  - Ignora competências já fechadas no backend.
  - Preserva `fechadoPor`/`motivo` originais; adiciona nota "Migração
    local (YYYY-MM-DD)" quando não há motivo.
  - Após sucesso, esvazia o array local para evitar recontagem.
- `CompetenciaFechamentoBar` chama o hook — reconciliação ocorre ao
  abrir a Fopag pela primeira vez após login.

## Regras respeitadas
- Idempotente: flag em `localStorage` + verificação de existentes no
  backend antes de cada RPC.
- Segurança preservada: RPC continua exigindo `current_is_gm()`; falhas
  de permissão simplesmente não migram (a flag ainda é gravada para
  não repetir a varredura a cada render — o usuário GM subsequente
  ainda pode disparar via clique manual).
- Sem alteração no contrato do hook local ou remoto.

## Não escopo
- UI dedicada de reconciliação manual.
- Migração inversa (backend → local para uso offline).

## Validação
- `bunx tsgo --noEmit` — sem novos erros.
