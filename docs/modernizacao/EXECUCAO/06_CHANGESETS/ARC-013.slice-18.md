# ARC-013 · Slice 18 — Encapsular `cardChecklistItensRepo` em `useCards`

## Escopo
Migrar leituras/mutações de `cardChecklistItensRepo` para hooks/queryFns canônicos em `src/hooks/useCards.ts`, removendo imports diretos em `CardGenericoDialog`, `CardRecursoDialog` e `MoverCopiarCardMenu`.

## Alterações
1. **`src/hooks/useCards.ts`**
   - Import interno de `cardChecklistItensRepo`.
   - `cardsKeys.checklist(cardId)` (chave `["card-checklist", cardId]`).
   - `cardsQueryFns.listChecklistByCard(cardId)`.
   - Helper `invalidateChecklist(qc, cardId)` que invalida `cardsKeys.all/alertasPrazo/kanban/detail` + `cardsKeys.checklist`.
   - Mutations: `useInsertChecklistItem`, `useInsertChecklistItems`, `useSetChecklistItemConcluido`, `useUpdateChecklistItem`, `useUpdateChecklistGrupo`, `useRemoveChecklistItem`, `useRemoveChecklistGrupo`, `useRemoveChecklistByCard`. Todas aceitam `cardId` (opcional em item-based) para invalidação precisa.

2. **`src/components/cards/CardGenericoDialog.tsx`**
   - Remove `cardChecklistItensRepo` do import de `cardsExtra`.
   - Query de checklist usa `cardsKeys.checklist` + `cardsQueryFns.listChecklistByCard`.
   - `limparDadosSecao("checklist")` usa `removeChecklistByCardMut`.
   - `addChecklistItemEm`, `renomearGrupoChecklist`, `executarRemocaoGrupoChecklist`, `toggleChecklist`, `removeChecklist`, `atualizarItemChecklist` usam mutations canônicas.

3. **`src/components/cards/CardRecursoDialog.tsx`**
   - Remove `cardChecklistItensRepo` do import de `cardsExtra`.
   - `useQuery` combinado usa `cardsQueryFns.listChecklistByCard`.
   - `addCheck`/`toggleCheck`/`removeCheck` usam mutations canônicas.

4. **`src/components/cards/MoverCopiarCardMenu.tsx`**
   - Remove `cardChecklistItensRepo` do import de `cardsExtra`.
   - Clonagem: leitura via `cardsQueryFns.listChecklistByCard` + `useInsertChecklistItems.mutateAsync`.

## Validação
- `tsgo --noEmit`: limpo.
- `rg cardChecklistItensRepo src`: retorna apenas `useCards.ts` (canônico), o repositório em `cardsExtra.ts` e o teste de contrato (`repositories-contrato-c.test.ts`).
- Semântica: preservada (mesmos payloads Supabase + `refetch` local + invalidação de cache).
