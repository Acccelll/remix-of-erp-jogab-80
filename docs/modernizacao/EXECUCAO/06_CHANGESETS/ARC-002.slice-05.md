# ARC-002.slice-05 — ObrasContext (camada de compatibilidade)

**Onda:** 6 · **Prioridade:** P1 · **Tipo:** REF/MIGRAÇÃO
**Achado:** ARC-002 (god-context)

## Escopo

Quinto slice da extração de subcontextos de domínio a partir de `AppContext`. Cria `ObrasContext` como fachada populada por `useApp()`, sem mover estado real, para permitir migração incremental dos consumers.

## Mudanças materializadas

- Novo `src/contexts/ObrasContext.tsx` expondo `obras`, `addObra`, `updateObra`, `deleteObra` a partir de `useApp()`.
- `ObrasProvider` montado em `src/App.tsx` dentro de `ContratosProvider`, mantendo a ordem `App → Colaboradores → Patrimonios → Veiculos → Contratos → Obras → Empresa`.
- Nenhum consumer migrado nesta etapa; contrato público de `useApp()` inalterado.

## Critérios preservados

- Sem alteração de UI, persistência, permissões ou regras de obras.
- Estado real ainda vive em `AppProvider` via `useObrasState`.
- Typecheck (`tsgo`) verde.

## Próximo

Migrar consumers reais de mutações de obras (`Obras.tsx`, `admin/Empresas.tsx`, `admin/ImportarObras.tsx`) para `useObrasContext()`, mantendo `useApp()` apenas para catálogos/permissões residuais.
