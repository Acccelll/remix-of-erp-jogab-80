# ARC-004.slice-04 — Patrimônios migrados para paradigma único (TanStack Query mutations)

**Onda:** 6 · **Achado:** ARC-004

## Escopo
Migra `patrimonios` do CRUD imperativo para mutations TanStack Query.

## Mudanças
- **`src/hooks/usePatrimonios.ts`**: adiciona `useAddPatrimonio`, `useUpdatePatrimonio`, `useDeletePatrimonio` com padrão canônico (`onMutate` snapshot → `onError` restore → `onSettled` invalidate).
- **`src/contexts/patrimonios/PatrimoniosStateContext.tsx`**: reescrito — `patrimonios = usePatrimonios().data ?? []`; `setPatrimonios` vira wrapper `qc.setQueryData` compatível com `React.Dispatch<SetStateAction>` para preservar mobilizações/responsabilidades.
- **`src/contexts/app/usePatrimoniosState.ts`**: removido.

## Nota
Regra de negócio de histórico de cadastro e histórico automático de flags permanece no provider por depender de `currentPlayer` e do snapshot atual do cache.

- `tsgo --noEmit` limpo.
