## Alterações
- `src/components/suprimentos/__tests__/TrendSummary.test.tsx` (novo). Casos cobertos:

  2. Sem `onTogglePiora`: chips renderizam como spans, nenhum `role=button`.

  5. `piora=0` + inativo → botão `disabled`.
  6. `piora=0` + ativo → botão habilitado (permite desligar filtro).
