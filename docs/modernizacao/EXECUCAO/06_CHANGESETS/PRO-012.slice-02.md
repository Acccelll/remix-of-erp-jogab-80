# PRO-012 · slice-02 — Execução da contagem cíclica

## Escopo
Habilita a execução de uma contagem cíclica: congela o saldo esperado a
partir do repositório de estoque, permite lançar o saldo contado item a
item e calcula a divergência automaticamente.

## Alterações
- `src/pages/suprimentos/ContagensCiclicas.tsx`
  - Nova coluna **Ação** na tabela de planos com botões:
    - "Iniciar" (planejada) → congela `saldoEsperado` via
      `suprimentosRepo.listEstoqueSaldos()` filtrado pelo local do plano,
      move o status para `em_andamento` e registra `dataInicio`.
    - "Continuar" (em andamento) → reabre para lançar mais quantidades.
    - "Ver" (concluída) → exibe em modo somente leitura.
  - Novo dialog de execução com tabela de itens (código, descrição,
    esperado, contado, divergência). Divergência muda de cor
    (verde = 0, vermelho ≠ 0).
  - `Salvar parcial` mantém `em_andamento`; `Concluir` grava `concluida`
    e `dataConclusao`.

## Fora de escopo
- Emissão de movimento de ajuste no repositório oficial (Supabase).
- Filtro/seleção de itens por curva ABC (usa hoje todos os saldos do local).
- Aprovação hierárquica da contagem antes do ajuste.

Esses pontos entram nas próximas slices do PRO-012.

## Validação
- `bunx tsgo -p tsconfig.app.json` sem erros no módulo alterado.
- Persistência local via `atualizarContagemCiclica` reaproveita helpers
  criados na slice-01.
- Divergência recalculada por `recalcularDivergencias` para manter
  consistência com o storage.
