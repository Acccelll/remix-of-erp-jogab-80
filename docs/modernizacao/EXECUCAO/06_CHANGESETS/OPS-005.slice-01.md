# OPS-005.slice-01 — Amostragem determinística + buffer de eventos

**Onda:** 07 · Observabilidade
**Achado-base:** OPS-005 — "Sem coletor externo de eventos estruturados; volume alto sem estratégia de amostragem".
**Escopo desta fatia:** regras puras (amostragem + buffer). Sem I/O e sem transporte — apenas a base consumida pelo slice-02.

## Problema
`structured-logger` emite eventos localmente; enviá-los integralmente para um coletor externo seria caro em volume alto e romperia a coerência de traces (parte de uma correlação exportada, parte não).

## Entrega
1. **`src/lib/observability/sampling.ts`** (`@module-kind pure`)
   - `hashKey(str)`: FNV-1a 32-bit determinístico.
   - `shouldSample(event, { ratio })`:
     - `error` / `warn` → sempre passam (bypass do ratio).
     - `info` / `debug` → decisão por bucket determinístico em cima do `correlationId` (fallback: `event`).
     - Coerência de trace: toda uma correlação passa junta ou é descartada junta.
2. **`src/lib/observability/event-buffer.ts`** (`@module-kind pure`)
   - `EventBuffer({ capacity })` circular: `push / drain / size / droppedCount / resetDropped`.
   - Overflow descarta o mais antigo e incrementa o contador (visibilidade para métrica no slice-02).
3. **Testes** — 6 (`sampling`) + 3 (`event-buffer`) = 9 novos verdes.

## Validação
- `bunx vitest run src/lib/observability` → **39/39 verdes**.
- `bunx tsgo --noEmit` limpo.

## Fora de escopo
- Transporte HTTP (fetch com retry + flush por timer/tamanho).
- Integração com `installObservabilitySinks()` (adicionará sink que aplica `shouldSample` e enfileira em `EventBuffer`).
- Config de endpoint/ratio via env — vem no slice-02.

## Próximo passo
`OPS-005.slice-02` — sink integrado ao bootstrap: aplica `shouldSample`, enfileira em `EventBuffer` e faz flush em lote para o coletor externo (fetch tolerante a falha, backoff + `sendBeacon` em unload).
