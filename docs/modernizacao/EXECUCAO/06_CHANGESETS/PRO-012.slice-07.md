# PRO-012 · slice-07 — Exportação XLSX de contagem

## Escopo
Botão "Exportar XLSX" no diálogo de execução, disponível apenas para contagens `concluida`.
Gera arquivo com 3 abas:
- **Resumo**: metadados do plano (local, critério, responsável, datas, status, totais).
- **Itens**: código, descrição, unidade, saldo esperado, saldo contado, divergência, observação.
- **Ajustes**: código, descrição, unidade, tipo, quantidade, status, aplicado_em, aplicado_por, observação.

Nome do arquivo: `contagem_<local>_<data_planejada>.xlsx`.
