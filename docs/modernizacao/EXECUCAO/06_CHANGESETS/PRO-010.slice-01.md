# PRO-010 · slice-01 — OC/cotação em PDF + registro de saída

**Onda:** 08 · **Prioridade:** P1 · **Marco:** M7 · **Escopo:** SEQUENCIAL · **Dependência:** PRO-009

## Contexto (achado)
Suprimentos já conduzia cotação vencedora até OC, mas não tinha uma saída formal
para o fornecedor. O comprador precisava copiar dados da tela ou montar documento
fora do sistema.

## Entrega
Adicionar saídas formais em PDF para os dois pontos do fluxo:

1. **Pedido de Cotação** no mapa comparativo.
2. **Ordem de Compra** no detalhe da OC.

Cada exportação grava uma trilha local de saída com data, destinatário, canal e
usuário emissor, mantendo o padrão de persistência local aplicado nos módulos
principais enquanto as tabelas de Suprimentos seguem em consolidação no backend.

## Alterações

### `src/lib/suprimentos/export-pdf.ts` (novo)
- `exportPedidoCotacaoToPDF(...)`: gera PDF A4 com identificação da obra,
  item, quantidade, unidade, fornecedores destinatários e campos para resposta
  de preço/prazo/condição.
- `exportOrdemCompraToPDF(...)`: gera PDF A4 da OC com fornecedor, contato,
  e-mail, telefone, itens, quantidades, preço unitário, total e campos de
  assinatura.
- Usa `jspdf` + `jspdf-autotable`, sem I/O de rede.

### `src/lib/suprimentos/envios.ts` (novo)
- Registro local `SuprimentoEnvio` para `ordem_compra` e `pedido_cotacao`.
- Persiste em `localStorage` na chave canônica `gestaobra:suprimentos:envios`.
- Emite evento local para atualização da tela sem reload.

### `src/lib/storage/keys.ts`
- Nova chave `suprimentoEnvios` registrada no inventário canônico (EST-003).

### `src/hooks/useFornecedores.ts` e `src/lib/repositories/fornecedores.ts`
- Novo hook `useFornecedoresContatos()` com razão social, nome fantasia,
  contato, e-mail, telefone e status ativo.

### `src/pages/suprimentos/Cotacoes.tsx`
- Botão **Pedido PDF** no diálogo do mapa comparativo.
- Gera pedido para fornecedores já presentes nas propostas; se não houver
  propostas, lista fornecedores ativos.
- Exibe as últimas saídas registradas daquela cotação.

### `src/pages/suprimentos/OrdensCompra.tsx`
- Botão **PDF fornecedor** no detalhe da OC.
- Gera documento com fornecedor, obra, itens e total.
- Exibe as últimas saídas registradas daquela OC.

## Observação de backend
Foi tentada uma migração para persistir `suprimento_envios` no backend, mas o
ambiente atual rejeitou a FK porque `public.ordens_compra` não existe no schema
Cloud ativo. Para não bloquear o slice, o registro ficou local, alinhado à
memória técnica vigente de persistência local para dados principais.
