# PRO-029 · slice-03 — Índice de evidências fotográficas no PDF

**Onda:** 07 · **Prioridade:** P2 · **Marco:** M5 · **Depende de:** `PRO-029.slice-02`

## Contexto

O relatório PDF de inspeção listava respostas e NCs, mas silenciava as fotos
anexadas às respostas. Auditores recebiam o PDF sem saber quantas evidências
existiam nem a que pergunta cada arquivo pertencia, obrigando a abrir o bucket
manualmente.

## Entrega

- **`src/lib/inspecoes/export-pdf.ts`**
  - Nova seção "Evidências fotográficas (N)" quando `inspecao.fotos.length > 0`.
  - Tabela lista: #, Grupo, Pergunta, Arquivo (`path`), Legenda.
  - Mapa `respostaId → pergunta` construído a partir de `modelo.perguntas` +
    `inspecao.respostas` para resolver o vínculo sem consulta extra.
  - Cabeçalho verde (emerald 500) para diferenciar de respostas (azul) e NCs
    (vermelho); segue o mesmo estilo `autoTable` do restante.

## Impacto

- PDF continua puro (sem I/O, sem embed binário) — apenas referências textuais.
- Aparece somente quando há fotos; comportamento inalterado para inspeções sem
  evidências.
- Sem alteração de schema, permissões, hook ou fila offline.

## Validação

- Mudança isolada em função pura de export; harness roda typecheck/testes.
