**Escopo:** especificar, sem materializar, o patch mínimo de `scripts/sec002/verify-wave-2-preconditions.mjs` para satisfazer `E_WAVE2_PC4` com 29 linhas úteis auditadas em `.github/sec002-evidence/INDEX.md`.

## 1. Objetivo

Contratar R116 para aplicar um patch estritamente localizado em `verifyPC4()`, substituindo a expectativa literal de 26 linhas úteis por uma constante nomeada e auditável:

```javascript
const EXPECTED_INDEX_ROWS = 29;
```

O patch deve tornar `E_WAVE2_PC4` compatível com o estado atual e legítimo do `INDEX.md` sem alterar o índice, sem inferir contagem dinamicamente e sem promover o verificador a workflow obrigatório.

---

## 2. Estado de partida obrigatório

R116 só é válido se o estado de partida permanecer:

1. `scripts/sec002/verify-wave-2-preconditions.mjs` contém `SCHEMA_VERSION = "v2026-07-12.4"`.
2. `verifyPC4()` ainda valida `.github/sec002-evidence/INDEX.md`.
3. `verifyPC4()` ainda possui expectativa literal `26` para contagem e laço de numeração.
4. `.github/sec002-evidence/INDEX.md` possui exatamente 29 linhas úteis numeradas `1..29`, com schema `v2026-07-12.4`.
5. `E_WAVE2_PC4` falha antes do patch com a mensagem equivalente a `INDEX.md deve ter 26 linhas úteis; encontrado 29`.

Se qualquer item acima divergir, R116 deve parar e abrir nova spec corretiva, sem aplicar patch oportunista.
