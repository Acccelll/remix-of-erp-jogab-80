# PRO-002 · slice-02 — Follow-up visível na lista de oportunidades

## Contexto

A slice-01 criou tarefas de follow-up dentro do perfil e no dashboard M11. Ainda
faltava visibilidade operacional na lista principal de oportunidades, onde o
usuário prioriza a carteira.

## Entrega

- `src/hooks/useCrmTarefas.ts` — adiciona helper `proximaTarefaAberta()` para
  reutilizar a regra de próxima pendência aberta.
- `src/hooks/__tests__/useCrmTarefas.test.ts` — cobre classificação de prazo e
  seleção da próxima tarefa por oportunidade.
- `src/pages/crm/Oportunidades.tsx` — adiciona:
  - filtro **Follow-up** (`todos`, `com pendência`, `vencidos`, `sem follow-up`);
  - coluna **Próximo follow-up** com data, título e responsável;
  - exportação CSV com próximo follow-up, status e responsável.

## Não escopo

- Não altera persistência local da slice-01.
- Não cria edição inline de tarefa na tabela; a ação continua no perfil.
- Não muda os dados de interação/histórico.

## Validação

- `bunx vitest run src/hooks/__tests__/useCrmTarefas.test.ts` — OK.
- `bunx tsgo --noEmit --project tsconfig.qc001.json` — OK.
