## 2. Fonte normativa do escopo (R97)

`scripts/sec002/verify-wave-2-preconditions.mjs :: verifyPC4()` exige literalmente:

1. **Arquivo presente:** `.github/sec002-evidence/INDEX.md` deve existir e ser legível.
2. **Schema canônico:** o conteúdo deve conter o token `v2026-07-12.4` (compatível com `SCHEMA_VERSION`).
3. **Contagem exata:** o arquivo deve ter **exatamente 26** linhas úteis no formato `| <n> | …`.
4. **Numeração contínua:** cada linha `i ∈ [1..26]` deve estar presente exatamente uma vez.

Nenhuma outra propriedade é exigida por R97 nesta pré-condição; propriedades adicionais são permitidas desde que não violem (1)–(4).

## 4. Diagnóstico canônico

A defasagem entre `verifyPC4()` e o `INDEX.md` é **estrutural, não regressiva**: as linhas 27, 28 e 29 foram acrescentadas por changesets legítimos (R99 do próprio verificador, R103 do selo `SEC-001` CLOSED e R107 do PC2 artifact-01) após a materialização de R97. O verificador foi congelado com a contagem vigente no momento da sua materialização (26 linhas, estado pós-R93), e esse número precisa evoluir de forma controlada a cada self-register subsequente.

A correção contratada para R115/R116 tem **três características obrigatórias**:

1. **Somente `verifyPC4()` muda** — o `INDEX.md` permanece byte-a-byte imutável nas 29 linhas atuais.
2. **A expectativa numérica passa a ser derivada de uma constante nomeada** (`EXPECTED_INDEX_ROWS`) para permitir bumps subsequentes auditáveis por diff, sem lógica dinâmica que leia diretório ou infira contagem em runtime.
3. **Nenhuma alteração colateral** ao restante do verificador ou aos workflows.

## 5. Contrato do patch previsto para R115/R116

Bloco canônico mínimo do futuro patch em `scripts/sec002/verify-wave-2-preconditions.mjs`:

```javascript
// Constante nomeada, hoisted junto de SCHEMA_VERSION / PC_CODES
const EXPECTED_INDEX_ROWS = 29;

function verifyPC4() {
  const file = ".github/sec002-evidence/INDEX.md";
  const raw = readText(file, "PC4");
  requireMatch(
    "PC4",
    raw,
    new RegExp(SCHEMA_VERSION.replace(/[.]/g, "\\.")),
    `INDEX.md sem schema ${SCHEMA_VERSION}`,
    { path: file },
  );

  const rows = raw
    .split(/\r?\n/)
    .filter((line) => /^\|\s*\d+\s*\|/.test(line.trim()));

  if (rows.length !== EXPECTED_INDEX_ROWS) {
    throw failure(
      PC_CODES.PC4,
      `INDEX.md deve ter ${EXPECTED_INDEX_ROWS} linhas úteis; encontrado ${rows.length}`,
      { path: file, rows: rows.length, expected: EXPECTED_INDEX_ROWS },
    );
  }
  for (let i = 1; i <= EXPECTED_INDEX_ROWS; i += 1) {
    if (!rows.some((line) => new RegExp(`^\\|\\s*${i}\\s*\\|`).test(line.trim()))) {
      throw failure(PC_CODES.PC4, `linha útil ${i} ausente em INDEX.md`, { path: file, line: i });
    }
  }
}
```

Detalhes adicionais (comentário justificando a constante, exportação opcional para testes) são responsabilidade de R115 (spec do patch) e devem preservar as invariantes PC4S1–PC4S8 abaixo.
