# ARC-013 · Slice 19 — Encapsular `cardAnexosRepo` em `useCards`

## Escopo
Migrar leituras/mutações de `cardAnexosRepo` para hooks/queryFns canônicos em `src/hooks/useCards.ts`, removendo imports diretos em `useCardCovers`, `CardGenericoDialog`, `CardRecursoDialog` e `CommentEditor`. `cardAnexosStorage` (Supabase Storage) permanece consumido diretamente pelos componentes que fazem upload/download/remoção do bucket — é utilitário de I/O, fora do escopo desta slice.

## Alterações
1. **`src/hooks/useCards.ts`**
   - Import interno de `cardAnexosRepo`.
   - `cardsKeys.anexos(cardId)` (`["card-anexos", cardId]`) e `cardsKeys.coverPaths(ids)` (`["card-covers", ...ids]`).
   - `cardsQueryFns.listAnexosByCard`, `cardsQueryFns.listCoverPathsByCards`.
   - Helper `invalidateAnexos(qc, cardId)`.
   - Mutations: `useInsertCardAnexo`, `useRemoveCardAnexo`, `useRemoveCardAnexosByCard`.

2. **`src/hooks/useCardCovers.ts`**
   - Remove import direto de `cardAnexosRepo`; usa `cardsKeys.coverPaths` + `cardsQueryFns.listCoverPathsByCards`. Mantém `cardAnexosStorage.createSignedUrl` (I/O).

3. **`src/components/cards/CardGenericoDialog.tsx`**
   - Remove `cardAnexosRepo` do import de `cardsExtra`.
   - Query de anexos: `cardsKeys.anexos` + `cardsQueryFns.listAnexosByCard`.
   - `limparDadosSecao("anexos")` usa `removeCardAnexosByCardMut`.
   - `uploadAnexo` insere via `useInsertCardAnexo`.
   - `executarRemocaoAnexo` remove via `useRemoveCardAnexo`.

4. **`src/components/cards/CardRecursoDialog.tsx`**
   - Remove `cardAnexosRepo` do import; leitura via `cardsQueryFns.listAnexosByCard`; upload/remove via mutations canônicas.

5. **`src/components/cards/CommentEditor.tsx`**
   - Remove `cardAnexosRepo` do import; insert via `useInsertCardAnexo`.

## Validação
- `tsgo --noEmit`: limpo.
- `rg cardAnexosRepo src`: retorna apenas `useCards.ts` (canônico), o repo em `cardsExtra.ts` e o teste de contrato (`repositories-contrato-f.test.ts`).
- Semântica preservada: mesmos payloads Supabase; storage inalterado; `refetch` local mantido + invalidação de cache canônica.
