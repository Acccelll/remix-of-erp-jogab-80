# ARC-003.a — Canalizar `obras` via `obrasRepo`

**Onda:** 3 · **Prioridade:** P1 · **Tipo:** LOTE (parte A de ARC-003)

## Escopo

Eliminação de todo `supabase.from("obras")` em `src/pages/` e `src/components/`, redirecionando os 21 acessos para `obrasRepo`.

## Mudanças

### `src/lib/repositories/obras.ts` — novos métodos

- `listResumoComCodigoNome()` — `id, codigo, nome` ordenado por nome (ChecklistImport).
- `listComClienteId()` — `id, codigo, nome, cliente_id` (FinFluxo).
- `listMinContrato()` — `id, codigo, nome, valor_contrato` (CronogramaImporter).
- `getCentroCustoTotvs(id)` — coluna única (FinanceiroTab).
- `getNome(id)` — coluna única (Breadcrumbs).
- `getPedidoValorContrato(id)` — pedido+valor (BmsImporter).
- `listComCodigoTotvs()` — `id, nome, codigo, codigo_totvs` (FinFaturamento).
- `listDashboard()` — projeção do dashboard financeiro (FinDashboard).

### Call-sites refatorados (21)

- 15 usos do padrão `select("id, nome").order("nome")` em `Promise.all` → `obrasRepo.listResumo().then((data) => ({ data, error }))`, mantendo o destructuring existente:
  - `pages/suprimentos/{Requisicoes,Recebimento,OrdensCompra,Estoque,Cotacoes}.tsx`
  - `pages/planejamento/{Riscos,Restricoes,RdoConsolidado,PacotesTrabalho,LicoesAprendidas,DashboardLean,Lookahead,PPC}.tsx`
  - `pages/InspecaoCaptura.tsx`
  - `components/cards/ImportarTrelloDialog.tsx`
- Projeções específicas → novos métodos do repo:
  - `ChecklistImport.tsx` → `listResumoComCodigoNome`
  - `CronogramaImporter.tsx` → `listMinContrato`
  - `FinFluxo.tsx` → `listComClienteId`
  - `FinFaturamento.tsx` → `listComCodigoTotvs`
  - `FinDashboard.tsx` → `listDashboard`
  - `components/obra/FinanceiroTab.tsx` → `getCentroCustoTotvs`
  - `components/layout/Breadcrumbs.tsx` → `getNome`
  - `components/import/BmsImporter.tsx` → `getPedidoValorContrato`
- Mutações canalizadas:
  - `pages/financeiro/FinObras.tsx` → `obrasRepo.listComCliente`, `create`, `update`, `remove`
  - `components/obra/ReguaEditor.tsx` → `obrasRepo.update`
  - `pages/GMFeatureFlags.tsx` → `obrasRepo.listResumo`

## Validação

- `rg 'from\("obras"\)' src/pages src/components` → zero.
- `tsgo --noEmit` verde.
- Comportamento preservado (mesmas projeções, mesmas ordens de retorno).
