# ARC-002.slice-39 — Responsabilidades domiciliadas em provider próprio

**Onda:** 6 · **Achado:** ARC-002 (fatiar `AppProvider`)

## Escopo
Extrai o último domínio ainda em `AppProvider`: `responsabilidadesPatrimonios` (estado + query + operações puras `encerrarResponsabilidade`, `encerrarResponsabilidadesDoColaborador`, `getResponsabilidadeAtiva`) para um `ResponsabilidadesStateProvider` real, seguindo o padrão de slice-33..38.

## Mudanças
- **`src/contexts/responsabilidades/ResponsabilidadesStateContext.tsx`** (novo): domicilia estado, executa `useResponsabilidadesPatrimonios` com `useSyncQueryToState`, expõe `responsabilidadesPatrimonios`, `setResponsabilidadesPatrimonios`, `encerrarResponsabilidade`, `encerrarResponsabilidadesDoColaborador`, `getResponsabilidadeAtiva` (via `useRef`) e `responsabilidadesLoaded`. Depende de `usePatrimoniosStateContext().setPatrimonios` para efeitos colaterais em patrimônios.
- **`src/contexts/app/useMobilizacoes.ts`**: remove estado local `responsabilidadesPatrimonios` e as 3 operações puras. Recebe `getResponsabilidades` + `setResponsabilidadesPatrimonios` por Options para uso interno em `mobilizarPatrimonio` (criação/encerramento de períodos).
- **`src/contexts/AppContext.tsx`**: bridge `useResponsabilidadesStateContext()`; `dataLoaded` incorpora `responsabilidadesLoaded`; `useAppQueries` desmontado; `queryEnabled` local removido.
- **`src/contexts/app/useAppQueries.ts`**: **removido** — não há mais queries residuais em `AppProvider`.
- **`src/App.tsx`**: `<ResponsabilidadesStateProvider>` promovido acima de `<AppProvider>`, dentro de `<ContratosStateProvider>`.

## Hierarquia final de providers de dados
`OportunidadesStateProvider > ColaboradoresStateProvider > PatrimoniosStateProvider > VeiculosStateProvider > ContratosStateProvider > ResponsabilidadesStateProvider > AppProvider`.

## Validação
- `tsgo --noEmit` limpo.
- Consumidores intactos via fachada `useApp()`.

## Próximo
`AppProvider` agora é puramente um orquestrador de mobilizações + fachada. Próximo passo natural: extrair `useMobilizacoes` para um `MobilizacoesProvider` dedicado (encerra ARC-002).
