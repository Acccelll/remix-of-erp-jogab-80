# PRO-032 · slice-01 — Painel consolidado no hub de Contratos

**Onda:** 08 · **Achado:** PRO-032 (Dashboard consolidado M12) · **Marco:** M12.

## Contexto

O hub de Contratos oferecia Quadro, Lista e Fornecimento, mas nenhuma visão
de topo. Alertas e documentos a vencer viviam só no sino/banner. Faltava
uma tela única para responder "como estão os contratos hoje?".

## Entrega

- **`src/components/contratos/ContratosOverview.tsx`** (novo)
  - Reúne dados de `useContratosContext`, `useContratosVencendo`,
    `useContratoAlertaSilencio` e `useContratoDocumentosVencendo`.
  - Quatro cards:
    - Contratos ativos + valor mensal recorrente.
    - Alertas ativos + destaque quando há críticos.
    - Documentos a vencer + destaque para vencidos/hoje.
    - Alertas silenciados (informativo).
- **`src/pages/ContratosHub.tsx`**
  - Nova aba **Painel** (ícone `LayoutDashboard`) como primeira posição.
  - Demais abas mantêm ordem e comportamento.
