# ChangeSet DS-007 — KPI/StatCard unificado

**Onda:** 4 — Padronização  
**Status:** Concluído

## Problema
Cada dashboard reimplementava seu próprio card de indicador (`Kpi`, `KpiCard`, `KpiMini`, `KpiBox`, `Stat`, `StatCard`) com variações mínimas de tipografia, tom e classes utilitárias. 22 declarações locais distintas identificadas.

## Solução
- Novo primitivo `src/components/common/Kpi.tsx` com API única:
  - `label`, `value` (ReactNode), `tone` (`default|success|warning|danger|muted|primary`), `hint`, `icon`, `highlight`, `size` (`sm|md|lg`), `labelUppercase`, `tabularNums`, `onClick`.
- Substituição das reimplementações locais por wrappers finos ou alias direto do novo `Kpi` — mantendo os call sites intactos onde possível.

## Arquivos migrados (primeira leva)
- `src/pages/dp/Fopag.tsx` — alias direto (`Kpi as KpiCard`).
- `src/pages/dp/Provisoes.tsx` — alias direto.
- `src/pages/dp/HorasExtras.tsx` — alias direto.
- `src/pages/planejamento/RdoConsolidado.tsx` — wrapper (`size="lg"`).
- `src/pages/financeiro/FinFaturamento.tsx` — wrapper (`labelUppercase`).
- `src/pages/financeiro/FinLancamentos.tsx` — wrapper (`highlight` + `tone` derivado do sinal).
- `src/pages/financeiro/FinCentros.tsx` — wrapper (`tone` mapeado de `warn` → `warning`).
- `src/pages/PlanejamentoDashboard.tsx` — wrapper (`tone` mapeado `good|bad|warn`).
- `src/components/obra/LinhaBalancoTab.tsx` — wrapper (`tone warn`).
