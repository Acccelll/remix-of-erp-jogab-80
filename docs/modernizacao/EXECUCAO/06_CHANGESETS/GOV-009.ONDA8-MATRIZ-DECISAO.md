## 3. Dados mínimos para liberar execução

Cada decisão acima só é considerada **pronta** quando registrar:

1. sistema-alvo ou decisão explícita de não integrar;
2. owner operacional;
3. credenciais/segredos necessários e forma segura de provisionamento;
4. SLA esperado, política de retry e tratamento de falha;
5. ambiente de teste/homologação disponível;
6. critério de aceite mensurável para regressão e monitoramento.

## 4. Sequenciamento proposto após gates verdes
