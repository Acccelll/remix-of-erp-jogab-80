# EST-002 — Changeset (Onda 0)

**Achado:** Escopo multiempresa não flui para os dados (filtro não filtra).
**Prioridade:** P1 · **Complexidade:** Média · **Estratégia:** ISOLADA
**Branch equivalente:** `EST-002`

## Diagnóstico confirmado neste repositório

`EmpresaContext` publica `obraIdsDaEmpresa` e `filtrarObras` (ver `src/contexts/EmpresaContext.tsx`). Busca por `useEmpresa(` em todo `src/` retorna **um único consumidor** — `src/components/EmpresaSelector.tsx` — que só lê `empresas`, `empresaAtualId`, `setEmpresaAtualId`, `empresaAtual`. Nenhum consumidor de `filtrarObras` ou `obraIdsDaEmpresa` fora do próprio contexto. Confirma o achado: o fio existe, mas não é usado por nenhuma consulta.

## Restrição arquitetural encontrada

`AppProvider` é ancestral de `EmpresaProvider` em `src/App.tsx` (`AppProvider > EmpresaProvider > …`) porque `EmpresaContext` depende de `useApp()` para ler `currentPlayer`. Portanto **não é possível** filtrar `obras` diretamente dentro de `AppContext` (dependência circular). O fluxo correto é criar um hook de leitura acima do `AppContext`.

## Escopo entregue nesta sessão

### 1. Hook canônico `useObrasEscopo` — critério (d)

Novo arquivo `src/hooks/useObrasEscopo.ts` — o "fio" que combina `useApp().obras` com `useEmpresa().filtrarObras`. Retorna:

- `obras: Obra[]` — já recortadas pela empresa selecionada.
- `obraIdsVisiveis: Set<string> | null` — `null` quando modo "Todas" (GM).
- `isTodas: boolean`.
- `carregando: boolean`.
- `filtrarPorObra<T>(items)` — recorte reutilizável em coleções filhas (por `id` ou `obra_id`).

Comportamento formal:

- Empresa específica → devolve apenas obras dessa empresa (critério b).
- `empresaAtualId === null` (GM "Todas") → devolve tudo, sem recorte (critério c).

### 2. Adoção do hook na tela flagship — critério (b)

`src/pages/Obras.tsx` (listagem principal, ancorada em obra) migrada:

- `const { obras } = useApp()` → `const { obras } = useObrasEscopo()`.
- Mutações (`addObra`, `updateObra`, `deleteObra`) permanecem em `useApp()` porque não são leituras de escopo.

Com essa migração, um usuário multiempresa que trocar a empresa no seletor verá a listagem principal mudar em tempo real — evidência mínima para o critério (b). Nenhum caminho legado foi removido.
