# ChangeSet DS-010 — Paginação padrão

**Onda:** 4 — Padronização  
**Status:** Concluído

## Problema

O primitivo `pagination` existia, mas cada lista paginada renderizava sua própria barra com textos, botões e regras de habilitação diferentes.

## Solução

- Novo componente `PaginationControls` em `src/components/common/PaginationControls.tsx`:
  - API 1-based: `page`, `totalItems`, `pageSize`, `onPageChange`.
  - Resumo único: `Mostrando X–Y de Z`.
  - Navegação padronizada com `PaginationPrevious`, `PaginationLink` e `PaginationNext`.
  - Suporte a `disabled` para listas em carregamento.
- Localização do primitivo base `ui/pagination` para português.
- `DataTable` passou a usar o novo padrão, beneficiando todos os consumidores existentes.

## Arquivos migrados

- `src/components/ui/data-table.tsx`
- `src/pages/ControleDespesas.tsx`
- `src/pages/AprovacaoFinanceira.tsx`
