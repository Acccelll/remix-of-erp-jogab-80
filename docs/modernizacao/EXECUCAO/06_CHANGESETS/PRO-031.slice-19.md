# PRO-031 · slice-19 — Número customizado visível em Contratos

## Contexto
Slice-18 passou a emitir número parametrizado ao criar contrato mas o valor
não aparecia em nenhuma tela. Este slice expõe o número na listagem.

## Entrega
- `src/pages/Contratos.tsx`
  - Import de `getDocumentoNumeroLocal` + `listDocumentoNumeracaoLocal`.
  - `numeracoesContrato` memoizado por `contratos.length` — mapa
    `id -> numero`.
  - Helper `numeroContrato(id)` com fallback em cascata: map → storage →
    `CTR-{últimos 6 do id}`.
  - Nova coluna "Nº" (badge outline, 130 px) antes de "Locação/Serviços"
    no `<Table>` principal.
  - `colSpan` do estado vazio ajustado (9→10 com edição, 8→9 leitura).

## Escopo consciente
- Detalhe (`ContratoProfileDialog`) e exportações XLSX serão tratados em
  slice separado — hoje só a listagem é ponto de leitura primário.
- Sem migração para persistência backend — mantém o padrão localStorage
  compartilhado desde slice-14.

## Validação
- `bunx tsgo --noEmit`: limpo.
