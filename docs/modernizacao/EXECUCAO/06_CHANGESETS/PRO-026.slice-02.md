# PRO-026.slice-02 — Reconciliação Lean × CPM no DashboardLean

**Onda:** 7 · **Achado:** PRO-026 · **Tipo:** NEW · **Escopo:** SEQUENCIAL (M3, M4)

## Problema

Após a regra pura do `slice-01`, a reconciliação ainda não estava visível
para o gestor: itens CPM sem pacote, pacotes órfãos e divergências de
conclusão continuavam exigindo conferência manual fora do dashboard Lean.

## Alterações

`src/pages/planejamento/DashboardLean.tsx`:
- passa a carregar pacotes completos e itens de cronograma para alimentar
  `reconciliarLeanCpm`;
- adiciona KPI **Cobertura Lean×CPM** ao bloco executivo;
- adiciona seção **Reconciliação Lean × CPM** com resumo por obra;
- inclui drilldown de **Itens sem pacote** e **Lean concluído, CPM aberto**;
- mantém CTA para `/planejamento/pacotes` sem criar novo fluxo de edição.

`src/lib/planejamento/reconciliacao.ts`:
- normaliza também `concluida/concluído/concluída` como status CPM concluído.

## Não escopo

- Não altera schema/RLS/repositórios.
- Não escreve conclusão de volta no cronograma.
- Não cria edição inline no dashboard.
- Não adiciona drilldown dedicado para pacote órfão; o dashboard apenas
  contabiliza o risco e direciona para Pacotes.
