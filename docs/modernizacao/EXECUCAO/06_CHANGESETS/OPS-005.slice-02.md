# OPS-005.slice-02 — Sink externo com flush em lote, backoff e unload

**Onda:** 07 · Observabilidade  
**Achado-base:** OPS-005 — "Sem coletor externo de eventos estruturados; volume alto sem estratégia de amostragem".  
**Escopo desta fatia:** transporte do coletor externo no front, usando a base pura da slice-01.

## Problema
Após `sampling.ts` e `event-buffer.ts`, ainda faltava uma peça de I/O para exportar eventos estruturados sem travar a aplicação, sem recursão pelo próprio `fetch` instrumentado e sem perder tudo em falhas transitórias.

## Entrega
1. **`src/lib/observability/event-collector.ts`** (`@module-kind io`)
   - `ExternalEventSink` com `accept / flush / flushBeacon / start / dispose`.
   - `buildExternalEventsPayload(now, reason, events, dropped)` com schema versionado (`schemaVersion: 1`).
   - Aplica `shouldSample` antes de enfileirar.
   - Usa `EventBuffer` circular e envia lote via `POST` JSON com `keepalive`.
   - Backoff exponencial em falha; eventos drenados voltam para a frente do buffer.
   - `sendBeacon` em `pagehide`, `beforeunload` e `visibilitychange:hidden`.
   - Proteção anti-recursão: ignora eventos `sb.fetch.*` cujo `fields.url` é o endpoint do próprio coletor.
2. **`bootstrap.ts`**
   - `installObservabilitySinks()` instala `installExternalEventSink()`.
   - Sem endpoint (`VITE_OBSERVABILITY_ENDPOINT`), o sink é no-op.
3. **Testes** (`__tests__/event-collector.test.ts`)
   - Payload versionado.
   - Amostragem com bypass de `warn/error`.
   - Lote JSON + `keepalive` + contador de drops.
   - Requeue + backoff em falha.
   - Flush por `sendBeacon` no unload.
   - Anti-recursão do transporte.

## Validação
- `bunx vitest run src/lib/observability` → **45/45 verdes**.
- `bunx tsgo --noEmit` → limpo.

## Fora de escopo
- Provisionar ou escolher endpoint real do coletor.
- Retenção persistente offline do buffer entre reloads.
- UI operacional para visualizar ingestão.
