# ARC-013.slice-16 — Encapsular labels de cards em `useCards`

## Alterações
- **`src/hooks/useCards.ts`**
  - Imports internos: `cardLabelsRepo` e `cardLabelLinksRepo`.
  - `cardsKeys.labels` para a query canônica de etiquetas.
  - `cardsQueryFns.listCardLabels` e `listCardLabelLinksByCard`.
  - Hooks canônicos: `useInsertCardLabelLink`, `useInsertCardLabelLinks`, `useRemoveCardLabelLink`, `useRemoveCardLabelsByCard`.
- **`src/components/cards/CardGenericoDialog.tsx`**
  - Remove import direto de `cardLabelsRepo`/`cardLabelLinksRepo`.
  - Lista etiquetas via `cardsQueryFns.listCardLabels`.
  - Toggle/remoção em massa de etiquetas via mutations canônicas.
- **`src/components/cards/MoverCopiarCardMenu.tsx`**
  - Remove import direto de `cardLabelLinksRepo`.
  - Clonagem de labels via `cardsQueryFns.listCardLabelLinksByCard` e `useInsertCardLabelLinks`.

## Validação
- `tsgo --noEmit` limpo.
- `rg "cardLabelsRepo|cardLabelLinksRepo" src/components src/hooks` mantém os repositórios apenas encapsulados em `useCards.ts`.
