# ARC-013 · slice-25 — Encapsular `cardLocalRepo` em `useCards`

## Objetivo
Remover uso direto de `cardLocalRepo` em componentes; expor leitura/mutação apenas
via camada canônica `useCards.ts` (hooks + `cardsQueryFns` + `cardsKeys`).

## Mudanças
- `src/hooks/useCards.ts`
  - Import interno de `cardLocalRepo`.
  - `cardsKeys.local(cardId)` = `["card-local", cardId]`.
  - `cardsKeys.temLocal(cardId)` = `["card-tem-local", cardId]`.
  - `cardsQueryFns.getLocalByCard(cardId)` e `existsLocalByCard(cardId)`.
  - Helper `invalidateLocal(qc, cardId)` invalida `local`, `temLocal` e o detalhe do card.
  - Mutations: `useUpsertCardLocal`, `useRemoveCardLocalByCard`.
- `src/components/cards/CardLocalSection.tsx`
  - Remove import direto do repo. Usa `cardsKeys.local`, `cardsQueryFns.getLocalByCard`,
    `useUpsertCardLocal` e `useRemoveCardLocalByCard`. Invalidação passa a ser feita
    pelo hook (`onSettled`), removendo o `useQueryClient` manual.
- `src/components/cards/CardGenericoDialog.tsx`
  - Remove `cardLocalRepo` do import de `cardsExtra`.
  - Query `temLocal` usa `cardsKeys.temLocal` + `cardsQueryFns.existsLocalByCard`.
  - Remoção da seção "local" usa `useRemoveCardLocalByCard.mutateAsync`.

## Validação
- `tsgo --noEmit` limpo.
- `rg cardLocalRepo src` restrito a `useCards.ts` (canônico), `cardsExtra.ts` (definição)
  e teste de contrato.
- Semântica preservada: mesmas chaves de cache, mesmo `onConflict=card_id` no upsert.
