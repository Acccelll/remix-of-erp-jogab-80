# PRO-031 · slice-11 — Linhas institucionais em todos os PDFs formais

## Contexto
O slice-10 introduziu `getInstitucionalHeaderLines` e passou a consumi-lo apenas no `gerarBoletimPdf` (BMS). Os demais PDFs formais (RDO, Obra gerencial, Inspeção, Ordem de Compra, Pedido de Cotação) ainda mostravam somente o logotipo, deixando o cabeçalho institucional inconsistente entre módulos.

## Entrega
- **RDO PDF (`src/lib/rdo/export-pdf.ts`)**: `ExportRdoPdfOpts.institucionalLines?` opcional. Renderiza cada linha em 8pt cinza logo abaixo do subtítulo (a partir de `y=77`, deslocando o `startY` da primeira tabela).
- **Obra gerencial (`src/lib/obras/export-pdf.ts`)**: mesmo padrão — nova prop opcional, bloco desenhado a partir de `y=76`, `startY` da identificação recalculado.
- **Inspeção (`src/lib/inspecoes/export-pdf.ts`)**: `institucionalLines` adicionado ao `ExportOpts`; layout idêntico ao acima.
- **Suprimentos (`src/lib/suprimentos/export-pdf.ts`)**: `header()` passou a aceitar `institucionalLines` e retornar o `startY` seguinte. `exportOrdemCompraToPDF` e `exportPedidoCotacaoToPDF` recebem prop opcional e repassam ao header.

## Consumidores atualizados
- `src/components/obra/RdoTab.tsx`: passa `institucionalLines: getInstitucionalHeaderLines(empresaId)`.
- `src/pages/financeiro/FinObraDetalhe.tsx`: idem, usando `obra.empresa_id`.
- `src/pages/InspecaoCaptura.tsx`: idem, com `empresaId` resolvido via obra.
- `src/pages/suprimentos/OrdensCompra.tsx` e `Cotacoes.tsx`: idem, com `empresaAtualId`.

## Escopo consciente
- Não altera dados persistidos nem contratos de repositórios.
- Não introduz nova UI de configuração — reaproveita o modelo institucional já capturado no slice-10.
- Layout preservado: quando `institucionalLines` é vazio, o `startY` original (82/80) é mantido, garantindo pixel-parity com PDFs anteriores.

## Validação
- `bunx tsgo --noEmit` limpo.
- Manual: em obra vinculada a empresa com dados institucionais, exportar RDO / relatório de obra / inspeção / OC / cotação passa a mostrar razão social·CNPJ e endereço·contato logo abaixo do título.
