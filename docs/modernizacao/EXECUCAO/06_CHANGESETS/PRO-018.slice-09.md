# PRO-018 · slice-09 — Diff/indicador visual de perfil BMS alterado

**Onda:** 07 · **Achado:** PRO-018 · **Data:** 2026-07-14

## Entrega
- `src/lib/bms/layoutPerfis.ts`: nova função pura `diffPerfis(a, b)` que
  retorna a lista de campos divergentes (`nome`, `cliente`, `headerRow`,
  `colunas.<chave>`), usável para diff/badges/preview de importação.
- `src/lib/bms/__tests__/layoutPerfis.test.ts`: teste cobrindo diff simples
  (nome + coluna) e caso idêntico (lista vazia).
- `src/components/import/BmsImporter.tsx`: badge "alterado <data>" ao lado
  do rótulo `vN` para perfis com `versao > 1`, sinalizando visualmente que
  divergiram do estado original (útil após edição manual ou merge).

## Regras respeitadas
- Contrato aditivo: `diffPerfis` é auxiliar puro, sem alterar API existente.
- UI puramente informativa — não bloqueia fluxo de importação/edição.

## Não escopo
- Modal comparativo campo-a-campo antes de importar/salvar.
- Rollback para versão anterior (não há histórico persistido).
