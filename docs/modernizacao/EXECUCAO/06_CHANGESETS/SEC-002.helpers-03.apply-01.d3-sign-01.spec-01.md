## 1. Objetivo

Definir o contrato canônico para considerar válida a assinatura D-3 no documento
`docs/modernizacao/EXECUCAO/03_DECISOES/D-3-SEC-002.md`, sem preencher a decisão,
sem gerar `candidate.sql`, sem descomentar fixtures e sem materializar `helpers-03`.

Este round transforma o documento assinável R210' em um gate objetivo: apenas uma
assinatura completa, com opção única e data ISO-8601, poderá destravar
`SEC-002.helpers-03.apply-01.d3-sign-01.materialize-01`.

---

## 2. Contrato de validade D-3

A assinatura D-3 só será considerada válida se o §5 de `D-3-SEC-002.md` cumprir
simultaneamente todos os critérios abaixo:

| Campo | Obrigatório | Regra |
|-------|:-----------:|-------|
| Opção escolhida | ✅ | exatamente uma opção marcada: `D-3a` XOR `D-3b` XOR `D-3c` |
| Assinado por | ✅ | nome explícito do DRI Produto/Segurança ou substituto indicado |
| Papel | ✅ | `DRI Produto/Segurança` ou papel equivalente registrado |
| Data | ✅ | ISO-8601 completa |
| Request ref | ✅ | R209' · `SEC-002.helpers-03.apply-01.d3-request-01.spec-01.md` |
| Baseline doc | ✅ | R210' · `03_DECISOES/D-3-SEC-002.md` |
| Efeito declarado | ✅ | autoriza apenas `d3-sign-01.materialize-01`; não aplica `helpers-03` sozinho |

Qualquer rasura, múltipla opção marcada, ausência de data ISO-8601 ou assinatura sem
papel explícito mantém `helpers-03.apply-01` bloqueado.
