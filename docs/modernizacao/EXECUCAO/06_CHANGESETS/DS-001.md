# DS-001 — Arquitetura de formulários (RHF + zod + shadcn Form)

**Onda:** 5 — Regras  
**Achado:** DS-001 — "Ausência de arquitetura de formulários (ui/form.tsx morto)"  
**Dependências satisfeitas:** BIZ-003 (schemas zod centralizados em `src/lib/schemas/*`).

## Escopo

1. Introduzir o padrão **shadcn `Form`** (wrapper de `react-hook-form`) como
   arquitetura única para formulários do sistema.
2. Publicar `src/components/ui/form.tsx` (antes ausente — dependências
   `react-hook-form@^7.61` e `@hookform/resolvers@^3.10` já instaladas).
3. Migrar um formulário-exemplar para provar o padrão sem regressão.
4. Definir a convenção que os próximos formulários devem seguir.

Fora de escopo desta changeset: migração em massa dos formulários existentes
(será feita incrementalmente, um por vez, referenciando este ID).

## Convenção (obrigatória para formulários novos/refatorados)

- **Estado do formulário:** `useForm` + `zodResolver(schema)`. Nunca replicar
  campo-a-campo em `useState`.
- **Schema:** vem de `src/lib/schemas/*` (BIZ-003) quando o formulário edita
  uma entidade de domínio. Formulários sem entidade (ex.: autenticação,
  filtros locais) declaram schema local mínimo no próprio arquivo.
- **Estrutura JSX:**

  ```tsx
  <Form {...form}>
    <form onSubmit={form.handleSubmit(onSubmit)}>
      <FormField control={form.control} name="campo" render={({ field }) => (
        <FormItem>
          <FormLabel>...</FormLabel>
          <FormControl><Input {...field} /></FormControl>
          <FormMessage />
        </FormItem>
      )} />
    </form>
  </Form>
  ```

- **Erros de campo:** `<FormMessage />` (nunca `toast` para validação local).
- **Erros de submit (rede/servidor):** aplicar política QC-003
  (`toast.error` + `logger.error`), no `catch` do handler.
- **Loading:** `form.formState.isSubmitting` — não criar `useState` paralelo.

## Alterações

- **novo** `src/components/ui/form.tsx` — componente padrão shadcn (`Form`,
  `FormField`, `FormItem`, `FormLabel`, `FormControl`, `FormDescription`,
  `FormMessage`, `useFormField`) com JSDoc apontando para esta changeset.
- **refatorado** `src/pages/Login.tsx` — formulário-exemplar:
  - Substitui `useState` de `username`/`password`/`loading` por `useForm`
    + `zodResolver` (schema local `loginSchema`).
  - Idem para o diálogo "Esqueci minha senha" (schema local `forgotSchema`).
  - Preserva integralmente o UX visível (autofoco, placeholders, estados de
    erro/loading, layout do card e diálogo).
