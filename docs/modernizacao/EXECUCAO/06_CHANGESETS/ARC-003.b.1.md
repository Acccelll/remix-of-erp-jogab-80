# ARC-003.b.1 — Canalizar `fornecedores`, `requisicoes`, `insumos` via repositórios

**Onda:** 3 · **Prioridade:** P1 · **Tipo:** LOTE (parte B.1 de ARC-003)

## Escopo

Substituir 7 chamadas `supabase.from()` diretas às tabelas `fornecedores`, `requisicoes` e `insumos` em `src/pages/` por seus repositórios.

## Mudanças

### Repositórios estendidos

- `src/lib/repositories/insumos.ts` — novo `listResumoPrecos()` (`id, descricao, unidade, preco_unitario`).
- `src/lib/repositories/requisicoes.ts` — novo `listResumoObra(limit)` (`id, obra_id, observacao`).

### Call-sites refatorados (7)

- `pages/suprimentos/Cotacoes.tsx` → `fornecedoresRepo.listResumoAtivos` + `requisicoesRepo.updateStatus`.
- `pages/suprimentos/OrdensCompra.tsx` → `fornecedoresRepo.listResumo`.
- `pages/suprimentos/Recebimento.tsx` → `fornecedoresRepo.listResumo`.
- `pages/suprimentos/CurvaABC.tsx` → `insumosRepo.listResumoPrecos`.
- `pages/suprimentos/Orcamento.tsx` → `insumosRepo.listPrecos`.
- `pages/planejamento/Restricoes.tsx` → `requisicoesRepo.listResumoObra`.

## Validação

- `rg 'from\("(fornecedores|requisicoes|insumos)"\)' src/pages src/components` → zero.
- `tsgo --noEmit` verde.
