# PRO-012 · slice-05 — Critérios "amostra" e "manual"

## Escopo
Habilita os critérios `amostra` (% aleatório reprodutível) e `manual`
(seleção de insumos) na criação do plano, e integra-os ao filtro
executado em `abrirExecucao`.

## Alterações
- `src/lib/estoque/contagens-ciclicas.ts`
  - Novos campos opcionais em `ContagemCiclica`: `amostraPct?: number`,
    `insumosSelecionados?: string[]`.
  - `CriarContagemInput` estendido com os mesmos campos.
  - `criarContagemCiclica` propaga os novos campos.
  - Novo helper `amostragemDeterministica(items, pct, seed)` — Fisher-Yates
    com PRNG `mulberry32` semeado por string (usa o `id` da contagem
    como seed para reprodutibilidade). Não é criptográfico.

- `src/pages/suprimentos/ContagensCiclicas.tsx`
  - Estado adicional: `amostraPct`, `insumosSel`, `insumoSearch`.
  - `canCreate` exige `amostraPct` válido (1–100) para "amostra" e
    ao menos um insumo selecionado para "manual".
  - Dialog "Nova contagem" mostra:
    - Campo `% da amostra` quando critério = amostra.
    - Busca + lista com checkboxes (limitada a 50 itens) quando
      critério = manual.
  - `abrirExecucao`:
    - `manual` → filtra `estoque_saldos` pelos ids selecionados.
    - `amostra` → aplica `amostragemDeterministica` sobre os saldos
      do local, usando `contagem.id` como seed.
  - Reset do formulário no `criar()` limpa seleção manual e busca.

## Fora de escopo
- Multi-select "grande" (>50 itens) com virtualização.
- Ordenação por curva ABC dentro do manual.
- Registro do `seed` explicitamente no plano (hoje = id da contagem).

## Validação
- `bunx tsgo -p tsconfig.app.json` sem erros novos.
- Critérios `curva_abc_A/B/C` seguem funcionando (slice-04 intacta).
- Reprodutibilidade: mesma contagem + mesmos saldos → mesma amostra.
