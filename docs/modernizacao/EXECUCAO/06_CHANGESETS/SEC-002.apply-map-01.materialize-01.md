# SEC-002.apply-map-01.materialize-01 — Materialização do mapa canônico de applies

**Onda:** 2 (bloqueada — depende de `SEC-001` fechar e da abertura formal da Onda 2)  
**Data:** 2026-07-12  
**Depende de:** `SEC-002.apply-map-01.spec-01` (R40), `SEC-002.apply-template-01.spec-01` (R32), `SEC-002.go-no-go-01.spec-01` (R33), `SEC-002.evidence-archive-01.spec-01` (R38), `SEC-002.errata-policy-01.spec-01` (R39)  
**Escopo:** materializar, em conteúdo canônico versionado neste documento, o artefato `.github/sec002-apply-map.json` e o loader compartilhado `scripts/sec002/load-apply-map.mjs` + validador `scripts/sec002/validate-apply-map.mjs`, tal como exigido por R40. **Nenhum arquivo em `src/`, `supabase/functions/` ou `supabase/migrations/` é alterado.** A gravação física dos três arquivos em `.github/` e `scripts/sec002/` ocorre apenas quando a Onda 2 abrir; até lá o conteúdo canônico vive aqui como fonte imutável.

## 1. Racional

R40 exigiu **contrato**. Sem materialização, cada validador (`validate-pr-checklist`, `validate-changed-files`, `validate-staging-parity`, `validate-go-no-go`, `validate-acceptance-gates`, `validate-evidence-archive`, `validate-errata`, `sec002-freeze-guard`) precisaria embutir sua própria cópia da lista de applies, tornando divergência inevitável. Este changeset congela o conteúdo exato dos três arquivos, com hashes esperados, para que a gravação futura seja mecânica e auditável.

## 3. Artefato 2 — `scripts/sec002/load-apply-map.mjs` (canônico)

**Caminho de destino:** `scripts/sec002/load-apply-map.mjs`  
**Contrato de exportação:** ESM puro, sem dependências externas. Exporta `loadApplyMap()`, `getApply(applyId)`, `listApplies()`, `SCHEMA_VERSION`.

```js
// scripts/sec002/load-apply-map.mjs
// Loader compartilhado do mapa canônico de applies SEC-002.
// Fonte única: .github/sec002-apply-map.json
// Contrato imutável definido em: docs/modernizacao/EXECUCAO/06_CHANGESETS/SEC-002.apply-map-01.materialize-01.md

import { readFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { dirname, resolve } from "node:path";

const __dirname = dirname(fileURLToPath(import.meta.url));
const MAP_PATH = resolve(__dirname, "..", "..", ".github", "sec002-apply-map.json");

export const SCHEMA_VERSION = "v2026-07-12.1";

let _cache = null;

export function loadApplyMap() {
  if (_cache) return _cache;
  const raw = readFileSync(MAP_PATH, "utf8");
  const parsed = JSON.parse(raw);
  if (parsed.schema_version !== SCHEMA_VERSION) {
    throw new Error(
      `[sec002] apply-map schema_version mismatch: expected ${SCHEMA_VERSION}, got ${parsed.schema_version}`
    );
  }
  _cache = Object.freeze(parsed);
  return _cache;
}

export function listApplies() {
  return loadApplyMap().applies;
}

export function getApply(applyId) {
  const found = listApplies().find((a) => a.apply_id === applyId);
  if (!found) {
    throw new Error(`[sec002] unknown apply_id: ${applyId}`);
  }
  return found;
}
```

## 4. Artefato 3 — `scripts/sec002/validate-apply-map.mjs` (canônico)

**Caminho de destino:** `scripts/sec002/validate-apply-map.mjs`  
**Contrato:** invocável por `node scripts/sec002/validate-apply-map.mjs`. Saída `0` = OK, `1` = qualquer invariante M1–M10 falha. Sem dependências externas.

```js
// scripts/sec002/validate-apply-map.mjs
// Validador determinístico das invariantes M1–M10 do apply-map.

import { loadApplyMap, SCHEMA_VERSION } from "./load-apply-map.mjs";

const errors = [];
const push = (m) => errors.push(m);

const map = loadApplyMap();

// M1
if (map.schema_version !== SCHEMA_VERSION) push(`M1 schema_version inválido: ${map.schema_version}`);

// M2
map.applies.forEach((a, i) => {
  if (a.order !== i + 1) push(`M2 order fora de sequência em index ${i}: ${a.order}`);
});

// M3
const ids = map.applies.map((a) => a.apply_id);
if (new Set(ids).size !== ids.length) push(`M3 apply_id duplicado em ${JSON.stringify(ids)}`);

// M4
const sum = map.applies.reduce((s, a) => s + a.expected_asserts, 0);
if (sum !== map.totals.sum_expected_asserts) push(`M4 soma expected_asserts=${sum} != totals=${map.totals.sum_expected_asserts}`);

// M5
const tests = map.applies.find((a) => a.apply_id === "tests-02-suite");
if (!tests || tests.expected_asserts !== map.totals.final_rls_suite_asserts) {
  push(`M5 tests-02-suite.expected_asserts != final_rls_suite_asserts`);
}

// M6
for (const a of map.applies) {
  for (const p of a.allowed_paths) {
    if (p.startsWith("src/") || p.startsWith("supabase/functions/")) {
      push(`M6 allowed_paths proibido em ${a.apply_id}: ${p}`);
    }
  }
}

// M7
for (const a of map.applies) {
  const migration = a.kind === "migration";
  const hasBatch = a.staging_batch != null;
  if (migration !== hasBatch || migration !== a.requires_staging_parity) {
    push(`M7 inconsistência kind/staging_batch/requires_staging_parity em ${a.apply_id}`);
  }
}

// M8/M9: presença é validada pelos consumidores especializados (go-no-go, evidence-archive);
// aqui garantimos apenas que os arrays existem e não estão vazios para applies de migração.
for (const a of map.applies) {
  if (!Array.isArray(a.specific_criteria) || a.specific_criteria.length === 0) {
    push(`M8 specific_criteria vazio em ${a.apply_id}`);
  }
  if (!Array.isArray(a.required_evidence_categories) || a.required_evidence_categories.length === 0) {
    push(`M9 required_evidence_categories vazio em ${a.apply_id}`);
  }
}

// M10
const closers = map.applies.filter((a) => a.closes_sec002 === true).map((a) => a.apply_id);
if (closers.length !== 1 || closers[0] !== "batch-E") {
  push(`M10 closes_sec002 esperado exatamente em batch-E, obtido ${JSON.stringify(closers)}`);
}

if (errors.length > 0) {
  console.error("[sec002/validate-apply-map] FAIL");
  for (const e of errors) console.error(" -", e);
  process.exit(1);
}
console.log("[sec002/validate-apply-map] OK");
```

## 5. Procedimento de gravação (quando a Onda 2 abrir)

1. Copiar §2 → `.github/sec002-apply-map.json` byte-a-byte (LF, UTF-8, sem BOM).
2. Copiar §3 → `scripts/sec002/load-apply-map.mjs`.
3. Copiar §4 → `scripts/sec002/validate-apply-map.mjs`.
4. Rodar `node scripts/sec002/validate-apply-map.mjs` → deve imprimir `[sec002/validate-apply-map] OK`.
5. Registrar manifest de evidência categoria `decision` em `.github/sec002-evidence/apply-map-01/manifest.json` com `sha256` dos três arquivos.
6. Qualquer divergência entre o JSON gravado e §2 é errata obrigatória (`SEC-002.errata-<seq>-apply-map`, severidade ≥ `medium`, `gm_required=true`).
