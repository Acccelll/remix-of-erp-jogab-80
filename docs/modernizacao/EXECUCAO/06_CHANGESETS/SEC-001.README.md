## 2. Problema central

O login atual mantém duas rotas paralelas de sincronização PHP↔Cloud:

| Rota | Cliente | Edge function | Email | Risco |
|------|---------|---------------|-------|-------|
| A | `ensureCloudSession` | `provision-auth-user` | real ou `@obraflow.local` | RBAC parcial se usado isoladamente |
| B | `ensureSupabaseSession` | `sync-player-auth` | `@planifik.local` | cria identidade duplicada |

Consequência: um mesmo login PHP pode virar dois usuários Cloud, quebrando `has_role(auth.uid(), ...)`, RLS, logout unificado e consultas protegidas.
