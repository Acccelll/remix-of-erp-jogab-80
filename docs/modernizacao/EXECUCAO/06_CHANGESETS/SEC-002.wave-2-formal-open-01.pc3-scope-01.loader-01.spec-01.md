### 2.1 Exports obrigatórios

| Export | Tipo | Descrição |
|--------|------|-----------|
| `SCHEMA_VERSION` | `string` | Literal `"v2026-07-12.4"` |
| `APPLY_MAP_PATH` | `string` | Literal `".github/sec002-apply-map.json"` |
| `loadApplyMap` | `(root?: string) => object` | Lê, parseia e valida o apply-map; retorna o objeto congelado (`Object.freeze`) |
| `default` | função | Alias de `loadApplyMap` |

### 2.2 Comportamento de `loadApplyMap(root?)`

1. `root` default = `process.cwd()`.
2. Resolve `abs = resolve(root, APPLY_MAP_PATH)`.
3. Lê `readFileSync(abs, "utf8")`. Falha de I/O → lança `Error` com `code = "E_APPLY_MAP_MISSING"` e `path = APPLY_MAP_PATH`.
4. `JSON.parse` do conteúdo. Falha → `Error` com `code = "E_APPLY_MAP_JSON"`.
5. Valida `data.schema_version === SCHEMA_VERSION`. Divergência → `Error` com `code = "E_APPLY_MAP_SCHEMA"`, `expected`, `actual`.
6. Retorna `Object.freeze(data)`.

Nenhuma escrita, nenhum cache mutável, nenhum efeito colateral fora do stdout do próprio `Error`.
