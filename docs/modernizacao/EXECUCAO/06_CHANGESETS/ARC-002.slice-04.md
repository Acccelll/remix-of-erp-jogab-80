# ARC-002.slice-04 — ContratosContext (camada de compatibilidade)

**Onda:** 6 · **Prioridade:** P1 · **Tipo:** REF/MIGRAÇÃO
**Achado:** ARC-002 (god-context)

## Escopo

Quarto slice da extração de subcontextos de domínio a partir de `AppContext`. Cria `ContratosContext` como fachada populada por `useApp()`, sem mover estado real, para permitir migração incremental de consumers.

## Mudanças materializadas

- Novo `src/contexts/ContratosContext.tsx` expondo `contratos`, `addContrato`, `updateContrato`, `deleteContrato`, `mobilizarContrato` a partir de `useApp()`.
- `ContratosProvider` montado em `src/App.tsx` dentro de `VeiculosProvider`, mantendo a ordem `App → Colaboradores → Patrimonios → Veiculos → Contratos → Empresa`.
- Nenhum consumer migrado nesta etapa; contrato público de `useApp()` inalterado.

## Critérios preservados

- Sem alteração de UI, persistência, permissões ou regras de mobilização de contratos.
- Estado real ainda vive em `AppProvider`.
- Typecheck (`tsgo`) verde.

## Próximo

Migrar consumers reais de contratos (`Contratos.tsx`, `QuadroContratos.tsx`, `ContratosHub`, `Fornecimento.tsx`) para `useContratosContext()`, mantendo `useApp()` apenas para catálogos/permissões residuais.
