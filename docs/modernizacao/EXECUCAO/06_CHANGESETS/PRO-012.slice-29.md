# PRO-012 · slice-29 — Reset inline do filtro "Somente em piora" no empty state

**Onda:** 07 · Suprimentos & Contagens Cíclicas
**Contrato:** UI-only.

## Escopo
No empty state da tabela de tendências, oferecer um atalho direto para desativar somente o filtro "Somente em piora" quando ele for a única causa da lista vazia (isto é, existem linhas em `rowsOrdenadas` mas nenhuma passa pelo filtro).

## Alterações
- `src/pages/suprimentos/ContagensCiclicas.tsx`:
  - Empty state agrupa os botões em um container flex.
  - Novo botão "Desativar filtro 'Somente em piora'" (`variant="secondary"`) exibido quando `apenasPiora && rowsOrdenadas.length > 0`. Chama `setApenasPiora(false)` diretamente (persistido pelo `useEffect` do slice-26).
  - Botão "Limpar filtros e ordenação" segue disponível quando `temPreferenciaTabela` é verdadeiro (útil quando o sort também contribui).

## Validação
- `bunx tsgo --noEmit` sem erros.
- Cenário coberto: usuário ativa "Somente em piora" quando não há piora → recebe mensagem + botão inline para desativar o filtro sem precisar mover o mouse até a toolbar.
