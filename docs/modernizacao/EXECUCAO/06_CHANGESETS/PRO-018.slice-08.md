# PRO-018 · slice-08 — Catálogo versionado de perfis BMS

**Onda:** 07 · **Achado:** PRO-018 · **Data:** 2026-07-14

## Entrega
- `src/lib/bms/layoutPerfis.ts`: cada `BmsLayoutPerfil` passa a carregar
  `versao` (>=1) e `atualizadoEm` (ISO). `criarPerfil` inicializa em `v1`;
  `atualizarPerfil` incrementa `versao` e atualiza `atualizadoEm` a cada patch.
- Importação (`importarPerfisJson`) ganha resolução de conflito determinística:
  compara `versao` primeiro e, em empate, `atualizadoEm`. Perfis locais mais
  recentes são **preservados**; perfis importados mais recentes **atualizam**
  os existentes. Novo campo `preservados` em `ImportarPerfisResultado`.
- Normalização aceita payloads antigos: perfis sem `versao`/`atualizadoEm`
  recebem `v1` e `criadoEm` como fallback, mantendo compatibilidade com JSON
  exportado pelo slice-07.
- `src/components/import/BmsImporter.tsx`: toast de importação inclui
  contagem de preservados; a lista de perfis salvos exibe o rótulo `vN`.
- `src/lib/bms/__tests__/layoutPerfis.test.ts`: novo teste garante que um
  perfil local com versão maior sobrevive à importação de uma versão antiga.
- `src/lib/bms/__tests__/excel-perfil.test.ts`: literal de perfil de teste
  atualizado para incluir `versao`/`atualizadoEm`.

## Regras respeitadas
- Contrato aditivo: campos novos com defaults; API pública anterior intacta.
- Persistência 100% local (`localStorage`), sem chamadas ao backend.
- Resolução de conflito puramente determinística — sem prompt interativo.

## Não escopo
- Sincronização remota ou catálogo corporativo compartilhado.
- Histórico de versões anteriores (mantém-se apenas a versão corrente).
- UI dedicada para diff/rollback de perfis.
