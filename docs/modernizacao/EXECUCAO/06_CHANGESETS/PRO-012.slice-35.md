# PRO-012 · slice-35 — Placeholder opt-in em TrendSummary (showWhenEmpty)

**Onda:** 07 · Suprimentos & Contagens Cíclicas
**Contrato:** UI-only + test.

## Escopo
Permitir que `TrendSummary` mantenha a moldura visual quando o recorte não tem dados, via nova prop opt-in `showWhenEmpty`.

## Alterações
- `src/components/suprimentos/TrendSummary.tsx`:
  - Novas props: `showWhenEmpty?: boolean` (default `false`), `emptyLabel?: string` (default `"Sem dados no período"`).
  - Quando `total === 0 && showWhenEmpty`, renderiza uma linha discreta `label: emptyLabel` (italic + opacity), preservando alinhamento com o layout normal.
  - Comportamento anterior (`return null`) permanece como default.
- `src/pages/suprimentos/ContagensCiclicas.tsx`:
  - Segundo `TrendSummary` (recorte 28 dias) recebe `showWhenEmpty` para nunca desaparecer.
- `src/components/suprimentos/__tests__/TrendSummary.test.tsx`:
  - Novo caso: `showWhenEmpty` exibe `label` + `emptyLabel`.

## Validação
- `bunx vitest run …/TrendSummary.test.tsx` → 7/7 verdes.
- `bunx tsgo --noEmit` sem erros.
