# PRO-021 · slice-03 — Edição da validade na aba Documentos

**Onda:** 08 · **Achado:** PRO-021 residual · **Depende de:** `PRO-021.slice-02`.

## Contexto

O `slice-02` introduziu o campo `validoAte` e a função pura de detecção,
mas a UI não permitia informar/editar a data — o campo ficava sempre nulo.

## Entrega

- **`src/hooks/useContratoDocumentos.ts`**
  - Nova ação `atualizarValidade(id, isoOuUndefined)` — normaliza string
    vazia para `undefined` e persiste.
- **`src/components/contratos/ContratoDocumentosSection.tsx`**
  - Nova coluna "Válido até" com `<input type="date">` por linha.
  - Editável quando `canEdit`; desabilitado caso contrário.
  - Destaque `destructive` quando a data já passou (comparação ISO local).

## Não escopo

- Integração no sino/banner (`slice-04`).
- Escolha de validade no momento do upload (usa fluxo edit-in-place).
- Notificações por e-mail.

## Validação

- `bunx tsgo --noEmit` limpo.
