# PRO-018 · slice-12 — Merge parcial campo-a-campo na importação

**Onda:** 07 · **Achado:** PRO-018 · **Data:** 2026-07-14

## Entrega
- `src/lib/bms/layoutPerfis.ts`:
  - Nova função pura `mergePerfilPorCampos(atual, importado, campos)` que
    aplica apenas os campos escolhidos do perfil importado sobre o atual,
    valida o resultado, bumpa `versao` e atualiza `atualizadoEm`.
  - Novo tipo `BmsLayoutImportDecisao` (união discriminada com
    `importar | preservar | mesclar`). `aplicarImportacaoPerfis` passa a
    aceitar decisão `mesclar` com `campos: BmsLayoutDiffCampo[]`.
- `src/hooks/useBmsLayoutPerfis.ts`: assinatura de `aplicarImportacao`
  atualizada para `BmsLayoutImportDecisao[]`.
- `src/components/import/BmsImporter.tsx`: adicionado botão **Mesclar**
  em perfis com conflito; ao selecioná-lo, a tabela ganha checkbox por
  linha para escolher quais campos do importado sobrescrevem o atual.
- `src/lib/bms/__tests__/layoutPerfis.test.ts`: dois testes cobrem o
  merge puro (preserva campos não marcados, bumpa versão) e a
  aplicação via `aplicarImportacaoPerfis` com ação `mesclar`.

## Regras respeitadas
- Contrato aditivo: união estende decisões existentes; API antiga
  (`importar`/`preservar`) segue funcional.
- Persistência 100% local; nenhuma decisão vai ao backend.
- Validação obrigatória do resultado do merge antes de persistir.

## Não escopo
- Merge automático de conflitos sem interação do usuário.
- Histórico de merges (mantém apenas o estado final).
