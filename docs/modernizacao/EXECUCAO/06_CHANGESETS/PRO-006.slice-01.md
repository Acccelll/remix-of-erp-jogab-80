# PRO-006 · slice-01 — Efetivo do RDO derivado da alocação do Board

## Contexto

Onda 07 · M1/M6. Hoje o RDO exige redigitar cada colaborador presente,
mesmo quando a mobilização já está gravada no Board de Obras. Esta slice
adiciona um atalho "Carregar do Board" que preenche a lista de efetivo
com os colaboradores mobilizados na obra, marcando todos como
`presente=true` para ajuste rápido pelo apontador.

## Entrega

- `src/components/obra/RdoTab.tsx` — botão **Carregar do Board** no card
  Efetivo. Usa a mesma query `rdo-colabs` já existente (mobilizações
  ativas sem `data_fim`), evita duplicar colaboradores já listados e
  respeita `canEdit`. Sem alteração de schema, sem alteração no fluxo
  de commit offline.

## Não escopo

- Sincronia bidirecional Board↔RDO (não altera o efetivo se a alocação
  mudar depois).
- Cálculo automático de faltas (o gestor ainda alterna o switch
  Presente/Ausente).
- Filtro por data específica de mobilização — a slice usa a lista
  de ativos correntes já cacheada (`data_fim IS NULL`).

## Validação

- `bunx tsgo --noEmit` — OK.
