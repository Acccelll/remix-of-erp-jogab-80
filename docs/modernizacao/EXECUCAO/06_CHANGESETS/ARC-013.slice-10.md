# ARC-013 · slice-10 — `updateReturningId` / `insertReturningId` / `getParaClonar` via hooks canônicos

**Onda:** 6 (ARC-013)
**Escopo:** eliminar imports diretos de `cardsRepo` nos consumidores restantes
(`CardGenericoDialog`, `MoverCopiarCardMenu`, `AdicionarRecursoDialog`) usando
novos hooks canônicos.

## Alterações

### `src/hooks/useCards.ts`
- `cardsQueryFns.getParaClonar(cardId)` — expõe leitura para clonagem.
- `useUpdateCardReturningId()` — mutation em `cardsRepo.updateReturningId`,
  invalida `cards`/`alertas-prazo`/`kanban-cards`/detalhe.
- `useInsertCard()` — mutation em `cardsRepo.insertReturningId`, invalida
  todo o namespace de cards.

### `src/components/cards/CardGenericoDialog.tsx`
- Remove import de `cardsRepo`.
- `updateCardReturningIdMut = useUpdateCardReturningId()`; `mudarCapa` passa
  a chamar `mutateAsync({ id, patch })`.

### `src/components/cards/MoverCopiarCardMenu.tsx`
- Remove import de `cardsRepo`.
- `cardsQueryFns.getParaClonar(cardId)` substitui `cardsRepo.getParaClonar`.
- `insertCardMut = useInsertCard()` substitui `cardsRepo.insertReturningId`
  na clonagem.

### `src/components/cards/AdicionarRecursoDialog.tsx`
- Remove import de `cardsRepo`.
- Loop de criação usa `insertCardMut.mutateAsync(payload)`.

## Validação

- `bunx tsgo --noEmit` — sem erros.
- Semântica preservada: `insertReturningId` mantém o shape `{data,error}` do
  Supabase, então blocos `if (e1)` seguem funcionando.
- Consumidores diretos de `cardsRepo` restantes: apenas `useCards.ts` e testes.
