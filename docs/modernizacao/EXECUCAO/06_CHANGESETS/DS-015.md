# DS-015 — Escala de Dialog + Barra de Filtros Padrão

**Onda:** 4 — Padronização
**Status:** Concluído (padrão publicado; migração incremental)

## Problema

- `DialogContent` sem escala oficial: cada tela decide `max-w-*` (`max-w-xs`, `sm`, `md`, `lg`, `2xl`, `3xl`, `4xl`, `5xl`, `[100vw]`) — 96 usos inconsistentes em `src/pages` e `src/components`.
- Barras de filtro reescritas página a página: `Input` + `Select` + botão limpar duplicados em ~20 telas, com espaçamentos e responsividade divergentes.

## Decisão

### 1. Escala oficial de Dialog

Prop `size` em `<DialogContent>` (default `lg`, preserva comportamento anterior):

| size   | max-width  | uso                                       |
| ------ | ---------- | ----------------------------------------- |
| `xs`   | `max-w-xs` | confirmação / prompt curto                |
| `sm`   | `max-w-sm` | form 1 coluna                             |
| `md`   | `max-w-md` | form médio                                |
| `lg`   | `max-w-lg` | **default** — form amplo / lista simples  |
| `xl`   | `max-w-2xl`| wizard / detalhe                          |
| `2xl`  | `max-w-3xl`| perfil / detalhe com abas                 |
| `3xl`  | `max-w-5xl`| dashboard embutido / card grande          |
| `full` | `100vw/dvh`| tela cheia (rounded-none)                 |

Novo padrão: use `size`. `className` fica reservado a ajustes marginais (`overflow-y-auto`, `max-h-*`).

### 2. `FilterBar` (`src/components/ui/filter-bar.tsx`)

Componente único com slots:

- `search` + `onSearchChange` + `placeholder` (esconde com `hideSearch`)
- `children` — filtros adicionais (Select, MultiSelect, DateRange)
- `onClear` — mostra botão "Limpar"
- `actions` — botões primários alinhados à direita

Responsivo: coluna no mobile, linha com wrap ≥ sm.

## Migração

**Fase 0 (esta entrega):** publica padrão + componente. Nenhuma tela quebrada — `DialogContent` sem `size` mantém `max-w-lg`.

**Fase 1 (próximas ondas / oportunista):** substituir `className="max-w-*"` em `DialogContent` por `size=...`. Substituir barras artesanais por `<FilterBar>`.

- `src/components/ui/filter-bar.tsx` — novo
