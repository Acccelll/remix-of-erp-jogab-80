# PRO-020 · slice-01 — Prévia de despesa recorrente a partir de contratos

**Onda:** 08 · **Achado:** PRO-020 (Contratos não geram despesa recorrente no Financeiro) · **Status:** ISOLADA · P2.

## Contexto
Contratos de locação/serviços já registram `valor`, `inicio` e `termino`, mas o Financeiro não enxerga o compromisso mensal. Esta primeira fatia entrega a **projeção** determinística — sem escrita no Financeiro — como base para as próximas slices que gerarão previsões/lançamentos reais na sub-onda financeira.

## Entrega
- `src/lib/contratos/recorrencia.ts` — módulo puro
  - `projetarRecorrencia(contrato, hoje?)` → `{ elegivel, mensalPrevisto, mesesRestantes, totalPrevisto }`
  - `projetarLista(contratos, hoje?)` → totais agregados
  - Regra: elegível quando `ativo && status ∉ {rascunho, encerrado} && valor>0 && inicio válido`; cadência mensal; sem `termino` → `mesesRestantes/totalPrevisto = null` (indeterminado).
- `src/pages/Contratos.tsx`
  - Novo card **"Recorrência prevista (mensal)"** no grid de totais (grid passa a 4 colunas)
  - Mostra soma mensal, quantidade de contratos elegíveis e total até término dentro do recorte filtrado (respeita busca, status, período, obra e reajustes via `valorComReajustes`).
