# DS-008 — Módulo único de gráficos (Recharts padronizado)

**Onda:** 4 — Padronização
**Achado:** DS-008 — Recharts cru em 24 arquivos; `ui/chart.tsx` com 0 usos

## Problema

Import direto de `recharts` espalhado por 23 arquivos, sem fonte única de paleta ou estilo de tooltip. Cada dashboard reintroduzia cores hex/tokens ad-hoc, quebrando consistência visual e travando qualquer futura troca de biblioteca de charts.

## Solução

Criado `src/components/ui/chart.tsx` como **único ponto de import de charts**:

- Reexporta a API do `recharts` (drop-in — nenhum call-site precisou mudar além do path).
- Expõe `CHART_COLORS` com paleta canônica via tokens HSL do design-system (`--primary`, `--accent`, `--secondary`, `--destructive`, `--muted-foreground`) + `CHART_COLORS.series` para séries múltiplas.
- Expõe `AppTooltip` e `APP_TOOLTIP_STYLE` com estilo de tooltip alinhado a `--popover`/`--border`/`--radius`.

Migração aplicada em 23 arquivos via `sed`, trocando `from "recharts"` por `from "@/components/ui/chart"`:

- `src/pages/{InspecoesDashboard,PlanejamentoDashboard}.tsx`
- `src/pages/dp/{PontoAnalise,HistoricoSalarial,HorasExtras,Provisoes,Fopag,Custos}.tsx`
- `src/pages/financeiro/{FinDividas,FinFluxo,FinLancamentos}.tsx`
- `src/pages/planejamento/{DashboardLean,PPC}.tsx`
- `src/pages/crm/CRMDashboard.tsx`
- `src/components/dashboard/{ResultadoAcumuladoPortfolioCard,PortfolioOverview,EvmPortfolioCard}.tsx`
- `src/components/obra/{DesempenhoTab,PrevistoRealizadoCard,ResultadoAcumuladoCard,FinanceiroTab,AnaliseTab}.tsx`
- `src/components/rh/EmployeeDPDialog.tsx`
