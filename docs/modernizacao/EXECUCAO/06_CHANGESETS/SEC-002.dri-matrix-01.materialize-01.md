# SEC-002.dri-matrix-01.materialize-01 — Materialização da matriz DRI

**Depende de:** `SEC-002.dri-matrix-01.spec-01` (R44), `SEC-002.apply-map-01.materialize-01` (R41), `SEC-002.apply-map-01.consumers-01.spec-01` (R42), `SEC-002.consumers-guard-01.spec-01` (R43)  
**Escopo:** materializar, em conteúdo canônico versionado neste documento, o runbook `docs/runbooks/sec-002-dri.md`, o template `.github/sec002-dri/_template.md`, o validador `scripts/sec002/validate-dri-matrix.mjs` e os deltas obrigatórios no apply-map/workflow. **Nenhum arquivo em `src/`, `supabase/functions/` ou `supabase/migrations/` é alterado.** A gravação física ocorre apenas quando a Onda 2 abrir.

## 1. Racional

R44 criou o contrato. Sem materialização, a matriz DRI continuaria dependente de interpretação manual e poderia divergir do apply-map, do checklist e dos guards. Este changeset congela o conteúdo operacional para que a futura gravação seja mecânica, revisável e auditável.

## 2. Delta obrigatório no apply-map

Antes de gravar os artefatos abaixo, o apply-map canônico deve evoluir para `schema_version = v2026-07-12.2` com estes deltas:

1. adicionar `scripts/sec002/validate-dri-matrix.mjs` em `consumers[]`;
2. adicionar `.github/sec002-dri/**` em `allowed_paths[]` de todos os applies;
3. adicionar `dri` em `required_evidence_categories[]` de todos os applies;
4. manter M1–M10 de R41, com os totais de asserts inalterados (`462` e `331`);
5. atualizar `SCHEMA_VERSION` de `load-apply-map.mjs` para `v2026-07-12.2` no mesmo changeset físico.

Motivo: sem esse delta, `validate-changed-files` bloquearia o registro `.github/sec002-dri/<apply-id>.md`, e `validate-evidence-archive` não exigiria a evidência DRI.

```md
# Runbook SEC-002 — Matriz DRI

## Objetivo

Garantir que cada apply SEC-002 tenha responsáveis primários, backups, segregação de aprovação e handoffs registrados antes do merge.

## Papéis obrigatórios

- dri_technical
- dri_platform
- dri_tests
- dri_observability
- dri_security
- comms_owner
- incident_commander
- gm_approver

## Procedimento pré-apply

1. Copiar `.github/sec002-dri/_template.md` para `.github/sec002-dri/<apply-id>.md`.
2. Preencher `window.starts_at` e `window.ends_at` em UTC.
3. Preencher `primary`, `backup` e `available=true` para todos os papéis.
4. Confirmar que `gm_approver.primary` não ocupa nenhum papel executor.
5. Preencher `handoffs.pre_apply` e `handoffs.rollback`.
6. Referenciar go/no-go, comms e acceptance do mesmo apply.
7. Rodar `node scripts/sec002/validate-dri-matrix.mjs --apply-id <apply-id> --file .github/sec002-dri/<apply-id>.md`.

## Troca durante janela

Troca de primary por backup exige errata operacional e atualização append-only no registro do apply. Não editar histórico silenciosamente.

## Pós-apply

Antes de aceitar o apply, preencher `handoffs.post_apply` com a evidência de passagem para observação T+24h ou handoff final.
```

## 5. Artefato 3 — `scripts/sec002/validate-dri-matrix.mjs` (canônico)

**Caminho de destino:** `scripts/sec002/validate-dri-matrix.mjs`  
**Contrato:** ESM puro, sem dependências externas, consome `load-apply-map.mjs`; saída `0` OK, `1` violação, `2` erro operacional.

```js
// scripts/sec002/validate-dri-matrix.mjs
// Validador determinístico da matriz DRI SEC-002.

import { readFileSync } from "node:fs";
import { getApply } from "./load-apply-map.mjs";

const REQUIRED_ROLES = [
  "dri_technical",
  "dri_platform",
  "dri_tests",
  "dri_observability",
  "dri_security",
  "comms_owner",
  "incident_commander",
  "gm_approver",
];

const errors = [];
const fail = (rule, detail) => errors.push(`${rule}: ${detail}`);

function arg(name) {
  const idx = process.argv.indexOf(name);
  return idx >= 0 ? process.argv[idx + 1] : null;
}

function parseScalar(value) {
  if (value === "true") return true;
  if (value === "false") return false;
  if (value === "null") return null;
  return value;
}

function setPath(root, path, value) {
  let node = root;
  for (let i = 0; i < path.length - 1; i += 1) {
    node[path[i]] ??= {};
    node = node[path[i]];
  }
  node[path[path.length - 1]] = value;
}

function parseFrontmatter(raw) {
  if (!raw.startsWith("---\n")) throw new Error("frontmatter ausente");
  const end = raw.indexOf("\n---", 4);
  if (end < 0) throw new Error("frontmatter sem fechamento");
  const body = raw.slice(4, end).split("\n");
  const root = {};
  const stack = [];
  for (const line of body) {
    if (!line.trim()) continue;
    const match = /^(\s*)([^:]+):(?:\s*(.*))?$/.exec(line);
    if (!match) throw new Error(`linha YAML inválida: ${line}`);
    const indent = match[1].length;
    const key = match[2].trim();
    const rawValue = match[3] ?? "";
    const depth = indent / 2;
    stack.length = depth;
    const path = [...stack, key];
    if (rawValue === "") {
      setPath(root, path, {});
      stack[depth] = key;
    } else {
      setPath(root, path, parseScalar(rawValue.trim()));
    }
  }
  return root;
}

function containsPlaceholder(value) {
  if (typeof value === "string") return /<[^>]+>/.test(value) || value.trim() === "";
  if (value && typeof value === "object") return Object.values(value).some(containsPlaceholder);
  return false;
}

try {
  const applyId = arg("--apply-id");
  const file = arg("--file");
  if (!applyId || !file) throw new Error("uso: --apply-id <id> --file <path>");
  getApply(applyId);

  const data = parseFrontmatter(readFileSync(file, "utf8"));

  if (data.sec002_apply_id !== applyId) fail("D2", `sec002_apply_id=${data.sec002_apply_id}`);
  if (data.matrix_version !== "v2026-07-12.1") fail("D3", `matrix_version=${data.matrix_version}`);

  for (const role of REQUIRED_ROLES) {
    const entry = data.roles?.[role];
    if (!entry) {
      fail("D4", `papel ausente ${role}`);
      continue;
    }
    if (!entry.primary || !entry.backup || typeof entry.available !== "boolean") fail("D4", `papel incompleto ${role}`);
    if (entry.primary && entry.primary === entry.backup) fail("D5", `primary=backup em ${role}`);
  }

  const gm = data.roles?.gm_approver?.primary;
  for (const role of REQUIRED_ROLES.filter((r) => r !== "gm_approver")) {
    if (gm && data.roles?.[role]?.primary === gm) fail("D6", `gm_approver acumula ${role}`);
  }

  if (data.approved_by?.dri_technical !== data.roles?.dri_technical?.primary) fail("D7", "assinatura técnica divergente");
  if (data.approved_by?.gm !== data.roles?.gm_approver?.primary) fail("D7", "assinatura GM divergente");

  const start = Date.parse(data.window?.starts_at ?? "");
  const end = Date.parse(data.window?.ends_at ?? "");
  if (!Number.isFinite(start) || !Number.isFinite(end) || start >= end) fail("D8", "janela inválida");
  if (Number.isFinite(start) && Number.isFinite(end) && end - start > 30 * 60 * 60 * 1000) fail("D8", "janela acima de 30h");

  const expectedRefs = {
    go_no_go: `.github/sec002-go-no-go/${applyId}.md`,
    comms: `.github/sec002-comms/${applyId}.md`,
    acceptance: `.github/sec002-acceptance/${applyId}.md`,
  };
  for (const [key, expected] of Object.entries(expectedRefs)) {
    if (data.evidence_refs?.[key] !== expected) fail("D9", `${key}=${data.evidence_refs?.[key]}`);
  }

  if (containsPlaceholder(data)) fail("D10", "placeholder ou campo vazio encontrado");

  if (errors.length) {
    console.error(`[sec002/dri-matrix] FAIL - ${errors.join("; ")}`);
    process.exit(1);
  }
  console.log("[sec002/dri-matrix] OK");
} catch (error) {
  console.error(`[sec002/dri-matrix] ERROR - ${error.message}`);
  process.exit(2);
}
```
