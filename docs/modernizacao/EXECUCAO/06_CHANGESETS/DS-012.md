# DS-012 — Casca padrão para diálogos de importação

**Onda:** 4 — Padronização
**Achado:** DS-012 — 8 diálogos de importação repetindo a mesma casca

## Problema

Cada diálogo de importação reescrevia `Dialog` + `DialogTrigger` + `DialogContent` + `DialogHeader` + `DialogTitle` (+ `DialogDescription` opcional) com as mesmas classes de tamanho e overflow. Mudanças de estilo exigiam tocar 4+ arquivos; título/descrição não tinham padrão único.

## Solução

Criado `src/components/import/ImportDialogShell.tsx` — componente que absorve a casca completa e expõe uma API mínima:

- `open` / `onOpenChange` — controle padrão.
- `title` / `description` — cabeçalho canônico via `DialogTitle` + `DialogDescription`.
- `trigger` — Botão de disparo (opcional; `Dialog` totalmente controlado quando ausente).
- `size` — enum de larguras (`max-w-lg`…`max-w-4xl`, default `max-w-2xl`).
- `children` — corpo do formulário; aplicado dentro de um wrapper `space-y-4`.

`DialogContent` já vem com `max-h-[90vh] overflow-y-auto` para forms longos.

Componentes rotulados como "import" que **não são diálogos** (mantêm-se como são):

- `src/components/import/BmsImporter.tsx`, `src/components/import/CronogramaImporter.tsx`, `src/components/import/CronogramaSemanalImporter.tsx` — componentes inline em página com wizard multi-etapa (só abrem sub-dialog auxiliar `MppNotSupportedDialog`).
