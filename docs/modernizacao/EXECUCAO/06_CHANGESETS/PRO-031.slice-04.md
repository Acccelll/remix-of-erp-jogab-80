# PRO-031 · slice-04 — Logotipo da empresa no PDF do RDO

**Onda:** 07 · **Achado:** PRO-031 (parametrização por empresa)
**Depende de:** PRO-031.slice-01 (repo/tipos), PRO-031.slice-02 (UI de logo), PRO-031.slice-03 (RDO consumindo numeração parametrizada)

## Contexto
Slices 01–03 entregaram o repositório de parametrização por empresa, a UI para
configurar logotipo/numeração e a integração da numeração no RDO. Faltava usar
o logotipo cadastrado nos documentos emitidos.

## Entrega
- `src/lib/rdo/export-pdf.ts`
  - `ExportRdoPdfOpts` ganha `logoDataUrl?: string`.
  - Cabeçalho renderiza o logo (48×48pt) à esquerda quando fornecido; título e
    linha de emissão deslocam para `x=100`. Formato inferido do prefixo do
    data URL (`JPEG` para `data:image/jpeg|jpg`, senão `PNG`).
  - Falhas em `addImage` são silenciosas — o PDF continua sendo gerado.
- `src/components/obra/RdoTab.tsx`
  - `handleExportarPdf` lê `empresaParametrizacaoRepo.get(empresaId).logoUrl`
    (fallback `undefined`) usando o `empresa_id` da obra e repassa para
    `exportRdoToPDF`.

## Escopo consciente
- Nenhuma alteração de fluxo de dados/regras de negócio: apenas cabeçalho.
- Sem upload/binário — usamos a URL cadastrada pela GM (data URL ou http[s]).
- Numeração/persistência permanecem em `localStorage` sob chave canônica.

## Validação
- `bunx tsgo --noEmit`: limpo.
- Slices 01/03 continuam com testes verdes (17/17 anteriores intactos).
