## 1. Objetivo

Este checkpoint existe para impedir abertura parcial ou ambígua da Onda 2. Antes do primeiro apply executável (`helpers-02`), o operador deve conseguir provar, em um único documento, que:

1. `SEC-001` saiu de NO-GO por fechamento formal do release train R1–R10;
2. o apply-map terminal permanece em `v2026-07-12.4`;
3. o índice de evidências possui 22 linhas canônicas;
4. os guards obrigatórios estão promovidos e protegidos;
5. o write set físico da Onda 2 está fechado;
6. nenhum artefato preparatório foi tratado como apply de produção.

Falha em qualquer item mantém a Onda 2 bloqueada.
