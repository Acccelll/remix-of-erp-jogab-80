# ARC-013 · slice-31 — encapsular `cronogramaRepo.listAtivosParaVinculoByObra` em hook canônico

## Contexto
`CardGenericoDialog` importava `cronogramaRepo` diretamente para popular o vínculo de etapas do cronograma. Slice segue o padrão ARC-013 de remover imports diretos de repositórios em componentes de UI.

## Alterações
1. **`src/hooks/useCronograma.ts`** (novo): expõe `cronogramaKeys.itensParaVinculoByObra(obraId)` e `cronogramaQueryFns.listAtivosParaVinculoByObra(obraId)`; tipo `CronogramaItemVinculo` centralizado.
2. **`src/components/cards/CardGenericoDialog.tsx`**: remove import de `cronogramaRepo`; passa a usar `cronogramaKeys`/`cronogramaQueryFns`. Semântica de query preservada (mesma chave string base, mesmo `enabled`).

## Escopo intencional
Rotinas de importação (`CronogramaImporter`, `CronogramaSemanalImporter`), recálculo CPM (`recalcular-cpm.ts`), abas de obra (`CronogramaPrincipalTab`, `RevisoesTab`, `LinhaBalancoTab`) e páginas financeiro/planejamento seguem consumindo `cronogramaRepo` diretamente — são fluxos com mutações compostas e transações que serão encapsuladas em slices dedicadas.

- `bunx tsgo --noEmit`: limpo.
- `rg cronogramaRepo src/components/cards`: sem ocorrências.
