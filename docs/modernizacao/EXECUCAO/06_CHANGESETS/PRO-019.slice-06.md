# PRO-019 · slice-06 — UI para reativar alertas silenciados

**Onda:** 08 · **Achado:** PRO-019 residual / M12 · **Depende de:** `PRO-019.slice-05`.

## Contexto

O `slice-05` permitiu silenciar alertas por 7 dias, mas o usuário não tinha
como listar os silenciados ativos nem cancelar antes do vencimento.

## Entrega

- **`src/components/layout/NotificationBell.tsx`**
  - Consome `mapa` e `reativar` do `useContratoAlertaSilencio`.
  - Dentro do painel de Preferências, nova seção "Alertas de contrato
    silenciados" (só renderiza quando existem entradas).
  - Cada linha mostra: nome do contrato (fallback `#<id>` truncado quando o
    contrato já não retorna alerta), tipo (`renovacao`/`reajuste`), data até
    quando o silêncio vigora, e ação **reativar** que chama `reativarSilencio`
    imediatamente.

## Não escopo

- Sem migração para persistência remota.
- Sem opções de silenciar por intervalos além dos 7 dias oferecidos no banner.
- Sem trilha de auditoria de quem silenciou.

## Validação

- `bunx tsgo --noEmit` limpo.
