# PRO-003.slice-05 — Hook remoto de fechamento DP (RPC + TanStack)

**Onda:** 07 · **Achado:** PRO-003 · **Slice:** 05/n

## Entrega
- `src/hooks/useDpFechamentoCompetenciaRemoto.ts`:
  - `useDpFechamentoCompetenciaRemoto` — lê `dp_fechamento_competencia`
    via TanStack Query e expõe `fechar` / `reabrir` chamando as RPCs
    `dp_fechar_competencia` e `dp_reabrir_competencia` (SECURITY DEFINER,
    validação de GM já no backend — slice-04).
  - `useDpFechamentoCompetenciaMerged` — escolhe automaticamente entre
    remoto (usuário autenticado) e local (fallback offline/sem sessão),
    mantendo o contrato do hook local (`ativo`, `fechar`, `reabrir`,
    `hydrated`).
- `CompetenciaFechamentoBar` migrada para o hook merged; handlers de
  fechar/reabrir viraram `async` para propagar erros de RPC via toast.

## Regras respeitadas
- Sem tocar em `types.ts`/`client.ts` (autogen).
- Permissão real continua no backend (`current_is_gm()` dentro das RPCs).
- Persistência local preservada como fallback — nenhuma quebra para
  usuários sem sessão.
- Invalida a query após cada mutação para manter cache coerente.
