# UX-002.slice-01 — Pesquisa global de registros no ⌘K

**Onda:** 7 · **Achado:** UX-002 · **Tipo:** NEW · **Escopo:** SEQUENCIAL

## Problema

O Command Palette (Ctrl/⌘+K) só oferecia navegação de telas + obras +
colaboradores. Não era possível localizar diretamente **patrimônios,
veículos ou clientes** por código/nome, forçando o usuário a abrir cada
módulo e usar a busca local.

## Alterações

`src/components/layout/CommandPalette.tsx`
- Imports adicionais: `usePatrimoniosContext`, `useVeiculosContext`, `useClientesContext`, ícones `Package`, `Car`, `Building`.
- Consome os três contextos existentes (sem novas queries).
- Novos grupos de resultado (limite 50 itens cada), com `value` composto para permitir busca por múltiplos campos:
  - **Patrimônios** — código + nome → `/patrimonios/lista`
  - **Veículos** — código + nome + tipo → `/veiculos`
  - **Clientes** — razão social + fantasia + CNPJ → `/crm/clientes`
- Placeholder do `CommandInput` atualizado para refletir os novos escopos.

## Validação

- `bunx tsgo --noEmit` limpo.
- Nenhuma alteração de dados/backend; contextos já providos globalmente pelo `Layout`.

## Estado

**UX-002 encerrado (fase 1).** Pesquisa global cobre agora obras, colaboradores, patrimônios, veículos e clientes.
Fases futuras (opcional): cards/oportunidades CRM, riscos e ordens de compra
via query dedicada — não bloqueiam o achado.
