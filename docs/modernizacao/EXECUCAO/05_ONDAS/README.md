# Índice das Ondas

## Resumo Executivo

Oito dossiês executivos originais (Onda 0 a 7) e uma Onda 8 em **KICKOFF** governado para integrações externas.

## Objetivo

Navegar entre as ondas de execução.

## Escopo

Onda 0 a Onda 7, com registro preparatório da Onda 8 enquanto os gates de partida não estão verdes.

## Conclusão

Execute em ordem. Nenhuma onda inicia sem aprovação formal da anterior quando houver dependência.
