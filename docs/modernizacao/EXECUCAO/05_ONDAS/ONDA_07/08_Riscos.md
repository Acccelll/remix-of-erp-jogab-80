# Onda 7 — Riscos

## Resumo Executivo

3 riscos identificados para esta onda, com probabilidade, impacto e mitigação.

## Objetivo

Antecipar o que pode dar errado e como conter.

## Escopo

Riscos de execução específicos da Onda 7.

## Conteúdo

| Risco                                           | Probabilidade | Impacto | Mitigação                                                |
| ----------------------------------------------- | ------------- | ------- | -------------------------------------------------------- |
| Escopo de produto expande sem controle          | Média         | Médio   | ID obrigatório; registro de desvio                       |
| Decisões D-4 e D-5 atrasam entregas dependentes | Média         | Baixo   | Registrar decisão antes de iniciar o item                |
| Documentação envelhece durante a própria onda   | Média         | Médio   | Documentação como subproduto incremental de cada entrega |

### Riscos herdados do programa

- Executar cirurgia de regressão **Muito Alta** sem caracterização E2E prévia.
- Ampliar escopo sem registro de desvio.
- Separar fusões obrigatórias em trabalhos distintos.

## Conclusão

Riscos contidos; mitigações são de baixo custo.
