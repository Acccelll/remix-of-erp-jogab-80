# Anexos

## Resumo Executivo

Espaço reservado para os artefatos de apoio produzidos **durante** a execução. Nasce propositalmente vazio de conteúdo de auditoria.

## Objetivo

Manter, junto da governança, os artefatos que a execução produzir e que precisem sobreviver ao programa.

## Escopo

O que **deve** ser depositado aqui ao longo das ondas.

## Conteúdo

| Artefato                                                | Produzido em   | Achado relacionado |
| ------------------------------------------------------- | -------------- | ------------------ |
| Registro de desvios (`DESVIOS.md`)                      | Todas as ondas | Contrato §5        |
| Registro das decisões D-1 a D-6, com data e responsável | Ondas 1 e 7    | Contrato §2        |
| Matriz de canonicidade entidade → dono                  | Onda 1         | `DB-005`           |

| Relatórios de build comparados (antes/depois)           | Ondas 0 e 6    | `PERF-001`         |
| Sumários de uma página por onda                         | Todas as ondas | Plano Mestre §5    |
| Runbooks operacionais                                   | Onda 7         | `OPS-007`          |

### Por que este diretório está vazio agora

A auditoria não produziu anexos: produziu **diagnóstico** (em [01_AUDITORIA](../01_AUDITORIA/)) e **planejamento** (em [EXECUCAO](../../EXECUCAO/)). Preenchê-lo com material fictício violaria a regra do pacote: _nenhum conteúdo inventado_.

## Conclusão

Este diretório é o destino dos artefatos de execução. Ele se preenche conforme as ondas avançam.
